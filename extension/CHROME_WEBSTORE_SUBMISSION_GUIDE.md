## 1. 提交前准备

### 1.1 账户准备

#### 创建Google账户

如果还没有Google账户：

1. 访问 https://accounts.google.com
2. 点击"创建账户"
3. 填写个人信息
4. 验证邮箱和电话
5. 完成账户创建

#### 注册Chrome Web Store开发者账户

1. 访问 https://chrome.google.com/webstore/developer/dashboard
2. 使用Google账户登录
3. 接受开发者协议
4. 支付一次性注册费（$5）
5. 完成账户设置

#### 验证账户

1. 验证邮箱地址
2. 添加支付方式（可选）
3. 完成身份验证

## 2. 提交步骤

### 步骤1: 访问开发者仪表板

1. 打开浏览器
2. 访问 https://chrome.google.com/webstore/developer/dashboard
3. 使用Google账户登录
4. 进入开发者仪表板

**预期结果**: 看到开发者仪表板主页

### 步骤2: 创建新项目

1. 点击"新建项目"按钮
2. 或点击"上传新项目"

**预期结果**: 进入项目创建页面

### 步骤3: 上传扩展包

1. 点击"选择文件"
2. 选择 `x-agent-extension.zip`
3. 点击"上传"
4. 等待上传完成

**预期结果**: 扩展包上传成功，显示项目ID

### 步骤4: 填写基本信息

#### 4.1 扩展名称

- 输入: X-Agent Browser Extension
- 长度: 45字符以内
- 确保准确和清晰

#### 4.2 简短描述

**中文版本**:
```
X-Agent浏览器扩展 - 智能网页自动化工具。自动识别页面元素、填充表单、提取内容、录制操作。与X-Agent桌面应用无缝协作，提升工作效率。
```

**英文版本**:
```
X-Agent Browser Extension - Intelligent web automation. Auto-identify elements, fill forms, extract content, record actions. Seamless integration with X-Agent desktop app.
```

- 长度: ≤ 132字符
- 清晰简洁
- 包含核心功能

#### 4.3 详细描述

使用已准备的详细描述文本。

- 包含功能列表
- 包含使用场景
- 包含系统要求
- 包含隐私保护说明

#### 4.4 分类

- 选择: 生产力工具
- 或: 开发者工具

#### 4.5 语言

- 选择: 中文 (简体)
- 选择: 英文

**预期结果**: 基本信息填写完成

## 3. 审核期间

### 3.1 审核时间

- **通常**: 3-5天
- **可能**: 1-2周
- **最长**: 30天

### 3.2 审核状态

访问开发者仪表板查看审核状态：

1. 登录开发者仪表板
2. 找到您的扩展
3. 查看"状态"列
4. 可能的状态：
   - 待审核 (Pending review)
   - 审核中 (In review)
   - 已批准 (Approved)
   - 已拒绝 (Rejected)
   - 已发布 (Published)

### 3.3 审核反馈

如果审核被拒绝：

1. 查看拒绝原因
2. 理解问题所在
3. 修复问题
4. 重新提交

**常见拒绝原因**:
- 权限过度
- 隐私政策不完整
- 虚假声明
- 恶意代码
- 违反政策

### 3.4 保持联系

- 检查邮件（包括垃圾邮件）
- 定期检查开发者仪表板
- 及时回复审核人员的问题
- 保持邮箱畅通

## 5. 常见问题

### Q: 提交后多久会被审核？

A: 通常3-5天，但可能需要更长时间。您可以在开发者仪表板查看状态。

### Q: 如果审核被拒绝怎么办？

A: 查看拒绝原因，修复问题，重新提交。通常可以快速重新审核。

### Q: 我可以在审核期间修改信息吗？

A: 不可以。审核期间无法修改。如果需要修改，必须等待审核完成。

### Q: 发布后可以修改信息吗？

A: 可以。发布后可以随时修改信息（除了扩展包本身）。修改会立即生效。

### Q: 如何更新扩展？

A: 修改版本号，构建新版本，上传到开发者仪表板，提交审核。

### Q: 如何删除扩展？

A: 在开发者仪表板中找到扩展，点击"删除"。删除后无法恢复。

### Q: 如何处理用户反馈？

A: 在开发者仪表板中查看评论，回复用户问题，修复报告的问题。

### Q: 如何提高用户评分？

A: 修复问题，改进功能，提供良好的用户体验，及时回复用户。

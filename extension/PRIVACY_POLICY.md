# X-Agent Chrome扩展 - 隐私政策

**生效日期**: 2024年5月28日  
**最后更新**: 2024年5月28日  
**版本**: 1.0.0

---

## 1. 简介

X-Agent浏览器扩展（以下简称"本扩展"）由X-Agent Team开发和维护。我们致力于保护用户隐私，并透明地说明我们如何处理数据。

本隐私政策解释了：
- 我们收集什么数据
- 我们如何使用数据
- 我们如何保护数据
- 用户拥有什么权利

---

## 2. 数据收集

### 2.1 我们收集的数据

#### 本地存储数据

本扩展在用户设备上本地存储以下数据：

| 数据类型 | 用途 | 存储位置 |
|---------|------|---------|
| 会话配置 | 管理自动化会话 | Chrome Storage |
| 操作历史 | 记录用户操作 | Chrome Storage |
| 用户偏好 | 保存用户设置 | Chrome Storage |
| 标签页组信息 | 管理标签页 | Chrome Storage |
| 元素缓存 | 加快元素识别 | Chrome Storage |

#### 临时内存数据

以下数据仅在内存中临时存储，不持久化：

- 当前页面的DOM树
- 识别的页面元素
- 用户交互事件
- 网络请求信息

### 2.2 我们不收集的数据

本扩展**明确不收集**以下数据：

- ❌ 个人身份信息（姓名、邮箱、电话等）
- ❌ 浏览历史
- ❌ 密码或敏感凭证
- ❌ 用户访问的网站内容
- ❌ 位置信息
- ❌ 设备标识符
- ❌ IP地址
- ❌ Cookie
- ❌ 用户代理信息
- ❌ 任何个人数据

### 2.3 数据收集方式

数据仅通过以下方式收集：

1. **用户操作** - 用户主动使用扩展功能时
2. **本地存储** - 用户设置和偏好
3. **页面交互** - 用户与网页的交互

**不通过以下方式收集**：
- 自动追踪
- 后台监控
- 第三方服务
- 分析工具

## 3. 数据使用

### 3.1 数据使用目的

我们仅将收集的数据用于以下目的：

#### 核心功能实现

- 页面元素识别和引用
- 表单自动填充
- 内容提取和分析
- 操作录制和回放
- 标签页管理

#### 用户体验改进

- 保存用户偏好设置
- 维护操作历史
- 管理会话状态
- 提供快速访问

#### 技术支持

- 调试问题
- 改进性能
- 优化功能

### 3.2 数据不会用于

我们**明确不会**将数据用于：

- ❌ 商业目的
- ❌ 第三方共享
- ❌ 广告投放
- ❌ 用户追踪
- ❌ 行为分析
- ❌ 个性化广告
- ❌ 数据销售
- ❌ 任何未经授权的目的

### 3.3 数据共享

本扩展**不与任何第三方共享数据**，包括：

- 分析公司
- 广告网络
- 社交媒体平台
- 数据代理
- 任何其他第三方

**例外情况**：
- 法律要求（如法院命令）
- 用户明确同意
- 防止欺诈或非法活动

## 4. 数据存储和安全

### 4.1 存储位置

所有数据存储在用户的本地设备上：

- **存储方式**: Chrome Storage API
- **存储位置**: 用户设备本地
- **访问权限**: 仅本扩展可访问
- **备份**: 用户可选择备份

### 4.2 数据安全措施

我们采取以下措施保护数据安全：

#### 加密

- 敏感数据本地加密
- 使用行业标准加密算法
- 加密密钥本地存储

#### 访问控制

- 仅本扩展可访问数据
- 其他扩展无法访问
- 网站无法访问

#### 安全通信

- 与服务器通信使用HTTPS
- 验证SSL证书
- 防止中间人攻击

#### 定期审计

- 定期安全审计
- 漏洞扫描
- 代码审查

### 4.3 数据保留

#### 保留期限

- 会话数据: 用户删除或会话结束时删除
- 操作历史: 用户可设置保留期限
- 用户偏好: 直到用户修改或删除
- 缓存数据: 定期自动清理

#### 数据删除

用户可随时删除数据：

1. **手动删除** - 通过扩展设置界面
2. **自动删除** - 卸载扩展时自动清除
3. **批量删除** - 支持批量删除功能
4. **导出后删除** - 导出数据后删除

## 5. 用户权利

### 5.1 访问权

用户有权访问本扩展存储的所有数据：

```javascript
// 查看所有存储的数据
chrome.runtime.sendMessage({
  type: 'GET_ALL_DATA'
}, response => {
  console.log('所有数据:', response.data);
});
```

### 5.2 删除权

用户有权删除任何数据：

```javascript
// 删除特定数据
chrome.runtime.sendMessage({
  type: 'DELETE_DATA',
  payload: { dataType: 'operationHistory' }
}, response => {
  console.log('数据已删除');
});
```

### 5.3 导出权

用户有权导出数据：

```javascript
// 导出所有数据
chrome.runtime.sendMessage({
  type: 'EXPORT_DATA',
  payload: { format: 'json' }
}, response => {
  console.log('数据已导出:', response.file);
});
```

### 5.4 拒绝权

用户有权拒绝数据收集：

- 禁用特定功能
- 调整权限设置
- 卸载扩展
- 清除所有数据

### 5.5 可携带权

用户有权以可读格式获取数据：

- JSON格式导出
- CSV格式导出
- 其他标准格式

## 6. 第三方服务

### 6.1 MCP通信

本扩展可与X-Agent桌面应用通过MCP协议通信：

- **通信方式**: 本地MCP协议
- **通信内容**: 用户指定的操作
- **数据安全**: 本地通信，不经过互联网
- **用户控制**: 用户可禁用此功能

### 6.2 不使用第三方服务

本扩展**不使用**以下第三方服务：

- ❌ 分析工具（Google Analytics等）
- ❌ 广告网络
- ❌ 追踪工具
- ❌ CDN（除了必要的库）
- ❌ 云存储
- ❌ 数据处理服务

### 6.3 外部库

本扩展可能使用以下开源库：

- 所有库都在本地运行
- 不向外部发送数据
- 用户可审查源代码

## 7. 儿童隐私

本扩展不针对13岁以下儿童。我们不会故意收集儿童的个人信息。

如果我们发现收集了儿童的信息，我们将立即删除。

### 9.3 其他地区

本扩展遵守所有适用的数据保护法规。

## 12. 常见问题

### Q: 扩展会收集我的浏览历史吗？

A: 不会。我们不收集浏览历史。我们仅在用户与扩展交互时处理当前页面。

### Q: 我的数据会被上传到服务器吗？

A: 不会。所有数据存储在本地设备上。我们不上传任何数据到服务器。

### Q: 扩展会追踪我吗？

A: 不会。我们不使用任何追踪工具或分析工具。

### Q: 我可以删除我的数据吗？

A: 可以。用户可随时删除任何数据。卸载扩展时会自动删除所有数据。

### Q: 扩展会与第三方共享数据吗？

A: 不会。我们不与任何第三方共享数据。

### Q: 如何验证隐私政策？

A: 用户可以：
1. 查看源代码（开源）
2. 使用浏览器开发者工具
3. 检查本地存储
4. 监控网络请求

# X-Agent Chrome扩展 - 权限声明文档

## 概述

本文档详细说明X-Agent Chrome扩展所需的所有权限及其用途。我们遵循最小权限原则，仅请求必要的权限。

---

## 权限详细说明

### 1. activeTab 权限

**用途**: 获取当前活跃标签页的信息

**具体应用**:
- 获取当前页面的URL
- 获取页面标题
- 在当前页面执行脚本
- 识别页面元素

**隐私影响**: 低
- 仅在用户与扩展交互时激活
- 不记录浏览历史
- 不跟踪用户活动

**必要性**: 必需
- 核心功能依赖此权限

---

### 2. scripting 权限

**用途**: 在网页中执行JavaScript脚本

**具体应用**:
- 识别和引用页面元素
- 获取元素属性和位置
- 执行表单填充操作
- 提取页面内容
- 高亮显示元素
- 监听用户交互

**隐私影响**: 中等
- 脚本仅在用户授权的页面执行
- 不访问用户密码或敏感数据
- 不修改页面内容（除非用户操作）

**必要性**: 必需
- 页面自动化的核心权限

---

### 3. webRequest 权限

**用途**: 监控和拦截网络请求

**具体应用**:
- 监控页面加载状态
- 调试网络问题
- 记录请求日志
- 优化性能

**隐私影响**: 中等
- 可能看到请求URL
- 不访问请求体或响应内容
- 仅用于调试和优化

**必要性**: 必需
- 确保扩展稳定性和性能

---

### 4. tabs 权限

**用途**: 管理浏览器标签页

**具体应用**:
- 创建新标签页
- 关闭标签页
- 切换标签页
- 获取标签页信息
- 管理标签页组

**隐私影响**: 中等
- 可以看到所有打开的标签页
- 不访问标签页内容
- 不记录浏览历史

**必要性**: 必需
- 标签页管理功能依赖

---

### 5. storage 权限

**用途**: 本地存储数据

**具体应用**:
- 保存会话配置
- 存储操作历史
- 保存用户偏好
- 缓存页面元素信息

**隐私影响**: 低
- 数据仅存储在本地
- 不上传到任何服务器
- 用户可随时删除

**必要性**: 必需
- 会话管理和数据持久化

---

### 6. webNavigation 权限

**用途**: 监控页面导航事件

**具体应用**:
- 检测页面加载完成
- 监控导航事件
- 处理页面切换
- 管理会话状态

**隐私影响**: 低
- 仅监控导航事件
- 不访问页面内容
- 不记录浏览历史

**必要性**: 必需
- 确保扩展与页面同步

---

### 7. contextMenus 权限

**用途**: 添加右键菜单选项

**具体应用**:
- 在页面右键菜单中添加选项
- 快速访问扩展功能
- 提高用户体验

**隐私影响**: 低
- 仅用于UI增强
- 不收集任何数据

**必要性**: 可选
- 增强用户体验
- 可禁用而不影响核心功能

---

### 8. offscreen 权限

**用途**: 在后台执行复杂计算

**具体应用**:
- 处理大量数据
- 执行复杂算法
- 避免阻塞主线程
- 提高性能

**隐私影响**: 低
- 仅用于计算
- 不访问用户数据

**必要性**: 可选
- 性能优化
- 可禁用而不影响功能

---

### 9. <all_urls> 主机权限

**用途**: 在所有网站上运行扩展

**具体应用**:
- 在任何网站上识别元素
- 填充任何网站的表单
- 提取任何网站的内容
- 支持用户访问的所有网站

**隐私影响**: 高
- 可以访问所有网站
- 需要用户信任

**必要性**: 必需
- 通用自动化功能

**隐私保护措施**:
- 不收集用户数据
- 不跟踪用户活动
- 不修改网站内容
- 所有数据本地存储
- 用户可随时禁用

## 权限最小化策略

### 已采取的措施

1. **使用activeTab限制**
   - 仅在用户与扩展交互时激活
   - 不持续监控所有标签页

2. **避免过度权限**
   - 不请求 `history` 权限
   - 不请求 `cookies` 权限
   - 不请求 `management` 权限

3. **本地数据存储**
   - 所有数据存储在本地
   - 不上传到服务器
   - 用户完全控制

4. **用户控制**
   - 用户可禁用特定功能
   - 用户可调整权限
   - 用户可卸载扩展

### 未来改进

- 实现更细粒度的权限控制
- 支持按网站配置权限
- 提供权限审计日志
- 定期审查权限使用

## 权限使用审计

### 权限使用日志

所有权限使用都记录在本地，用户可以查看：

```javascript
// 查看权限使用日志
chrome.runtime.sendMessage({
  type: 'GET_PERMISSION_AUDIT_LOG'
}, response => {
  console.log('权限使用日志:', response.logs);
});
```

### 权限使用统计

用户可以查看每个权限的使用频率和时间：

```javascript
// 获取权限使用统计
chrome.runtime.sendMessage({
  type: 'GET_PERMISSION_STATS'
}, response => {
  console.log('权限统计:', response.stats);
});
```

## 权限请求流程

### 首次安装

1. 用户从Chrome Web Store安装扩展
2. Chrome显示权限请求对话框
3. 用户可选择接受或拒绝
4. 接受后扩展获得权限

### 权限变更

1. 新版本可能请求新权限
2. Chrome通知用户
3. 用户可选择接受或拒绝
4. 拒绝则扩展功能受限

### 权限撤销

1. 用户可在Chrome设置中撤销权限
2. 扩展功能自动调整
3. 用户可重新授予权限

## 常见问题

### Q: 为什么需要<all_urls>权限？

A: 因为用户可能在任何网站上使用自动化功能。我们不能预知用户会访问哪些网站，所以需要通用权限。

### Q: 扩展会收集我的数据吗？

A: 不会。所有数据存储在本地，我们不收集任何用户数据。

### Q: 我可以禁用某些权限吗？

A: 可以。用户可在Chrome设置中调整权限。某些功能可能受限，但核心功能仍可用。

### Q: 如何验证权限使用？

A: 用户可以：
1. 查看权限使用日志
2. 检查本地存储数据
3. 使用浏览器开发者工具
4. 查看网络请求

### Q: 权限会被滥用吗？

A: 我们采取了多项措施防止滥用：
1. 开源代码，接受社区审查
2. 定期安全审计
3. 遵守Chrome Web Store政策
4. 透明的隐私政策

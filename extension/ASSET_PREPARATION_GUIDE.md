## 2. 图标设计指南

### 2.1 设计原则

#### 简洁性
- 简单清晰的设计
- 易于识别
- 避免过度复杂

#### 可识别性
- 在小尺寸下清晰可见
- 独特的视觉风格
- 与品牌一致

#### 可访问性
- 足够的对比度
- 易于区分
- 支持色盲用户

### 2.2 图标设计建议

#### 颜色方案

**推荐颜色**:
- 主色: 蓝色 (#0066CC)
- 辅色: 绿色 (#00AA00)
- 背景: 白色或透明
- 文字: 深灰色 (#333333)

#### 设计元素

- 使用简单的几何形状
- 避免过度装饰
- 保持一致的风格
- 考虑暗色模式

#### 文字和标志

- 如果包含文字，使用清晰的字体
- 避免过小的文字
- 确保在所有尺寸下可读

### 2.3 图标制作步骤

#### 步骤1: 创建基础设计

1. 在设计工具中创建1024x1024的画布
2. 设计主要图标
3. 确保设计清晰简洁
4. 测试在不同尺寸下的效果

#### 步骤2: 导出不同尺寸

```
原始设计 (1024x1024)
    ↓
128x128 (主图标)
48x48 (工具栏)
16x16 (标签页)
```

#### 步骤3: 优化和验证

1. 压缩文件大小
2. 验证透明度
3. 检查清晰度
4. 测试在Chrome中的显示

### 2.4 图标文件要求

#### 技术规格

- **格式**: PNG
- **颜色空间**: RGB或RGBA
- **透明度**: 支持
- **压缩**: 无损压缩

#### 文件命名

```
icon-128.png    # 主图标
icon-48.png     # 工具栏图标
icon-16.png     # 标签页图标
```

#### 文件位置

```
extension/
├── images/
│   ├── icon-128.png
│   ├── icon-48.png
│   └── icon-16.png
```

## 6. 资产优化指南

### 6.1 图像优化

#### PNG优化

```bash
# 使用ImageMagick优化PNG
convert input.png -strip -quality 95 output.png

# 使用pngquant压缩
pngquant --quality=80-95 input.png
```

#### JPG优化

```bash
# 使用ImageMagick优化JPG
convert input.jpg -strip -quality 85 output.jpg

# 使用mozjpeg压缩
mozjpeg -quality 85 input.jpg -o output.jpg
```

### 6.2 文件大小检查

```bash
# 检查文件大小
ls -lh *.png *.jpg

# 检查总大小
du -sh assets/
```

### 6.3 质量验证

1. 在不同设备上查看
2. 检查清晰度
3. 检查颜色准确性
4. 检查对比度

## 9. 常见问题

### Q: 图标应该有背景吗？

A: 不一定。透明背景更灵活，但纯色背景也可以。建议使用透明背景。

### Q: 截图可以包含文字吗？

A: 可以，但要确保文字清晰可读。建议使用简短的标注。

### Q: 宣传图可以包含文字吗？

A: 可以，但要确保文字清晰可读。建议使用简短的标题或标语。

### Q: 如何优化图像大小？

A: 使用图像压缩工具（如ImageMagick、pngquant等）。

### Q: 图像格式有什么要求？

A: 图标必须是PNG，截图和宣传图可以是PNG或JPG。

### Q: 如何验证资产质量？

A: 在不同设备上查看，检查清晰度、颜色和对比度。

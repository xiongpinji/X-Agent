   ```python

       hmac_secret="your-secret-key-here"
   )
   ```

2. **审计日志路径配置**
   ```python
   audit_store = AuditStore(
       storage_path="/var/log/xagent/audit.jsonl"
   )
   ```

3. **API密钥过期策略**
   - 默认: 90天自动过期
   - 可配置: 修改 `APIKeyRecord.expires_at`

4. **租户隔离规则**
   - 所有操作必须指定 `tenant_id`
   - 系统强制租户隔离

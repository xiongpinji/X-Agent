# 代码审查助手 / Code Review Assistant

**版本**: 1.0.0
**作者**: X-Agent Team
**描述**: 帮你检查代码有没有问题，就像有个经验丰富的程序员帮你看代码。
**关键词**: 代码, 审查, 质量, 调试, 优化, 最佳实践
**能力**: 代码分析, 质量检查, 性能优化, 安全审查, 最佳实践建议
**图标**: 🔍

## 这个技能是干什么的？

帮你检查代码有没有问题，就像有个经验丰富的程序员帮你看代码。

## 适合谁用？

- 新手程序员：学习写出更好的代码
- 团队leader：快速审查团队代码
- 自学者：没人帮忙看代码时用

## 怎么用？

1. 点击"一键使用"按钮
2. 把你的代码粘贴进去
3. 等几秒钟
4. 看到详细的审查报告，包括：
   - 哪里有bug
   - 哪里可以写得更好
   - 安全问题提醒
   - 性能优化建议

## 使用示例

```python
# 你的代码
def add(a, b):
    return a + b

# 审查结果会告诉你：
# ✓ 代码逻辑正确
# ⚠ 建议添加类型提示
# ⚠ 建议添加文档字符串
# 💡 改进建议：def add(a: int, b: int) -> int:
```

## 常见问题

**Q: 审查需要多长时间？**
A: 通常只需要几秒钟，取决于代码长度。

**Q: 支持哪些编程语言？**
A: 支持Python、JavaScript、Java、C++、Go、Rust等主流语言。

**Q: 审查结果准确吗？**
A: 我们使用最新的AI技术进行审查，准确率很高，但建议结合人工审查。

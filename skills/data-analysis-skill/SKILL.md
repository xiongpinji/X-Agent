# 数据分析助手 / Data Analysis Assistant

**版本**: 1.0.0
**作者**: X-Agent Team
**描述**: 快速分析数据、生成图表、制作报告，让数据说话。
**关键词**: 数据, 分析, 统计, 可视化, 报表, 图表
**能力**: 数据清洗, 统计分析, 数据可视化, 报表生成, 趋势预测
**图标**: 📊

## 这个技能是干什么的？

帮你分析数据、制作图表、生成报告，让数据说话。不需要懂复杂的统计学，也能得到专业的分析结果。

## 适合谁用？

- 数据分析师：加快分析速度
- 业务人员：理解数据含义
- 学生：完成数据作业

## 怎么用？

1. 上传你的数据文件（Excel、CSV等）
2. 选择分析类型
3. 等待分析完成
4. 查看图表和报告

## 使用示例

```
输入：销售数据表格
输出：
- 销售趋势图
- 地区对比分析
- 产品排名
- 增长预测
```

# X-Agent 本地端三端同步架构设计

**版本**: 1.0  
**日期**: 2026-05-27  
**目标**: 为X-Agent提供完整的本地端数据管理、隐私保护和三端同步能力

---

## 1. 架构概览

### 1.1 三端架构模型

```
┌─────────────────────────────────────────────────────────┐
│                    云端 (Cloud)                         │
│  - 中央数据库 (PostgreSQL)                              │
│  - 向量数据库 (Qdrant)                                  │
│  - 可观测性 (Langfuse)                                  │
│  - 协作与共享                                           │
└─────────────────────────────────────────────────────────┘
                          ↕ (同步)
┌─────────────────────────────────────────────────────────┐
│                  本地端 (Local)                         │
│  - SQLite本地数据库                                     │
│  - 文件系统管理                                         │
│  - 本地缓存                                             │
│  - 增量同步引擎                                         │
│  - 冲突检测与解决                                       │
│  - 离线队列管理                                         │
└─────────────────────────────────────────────────────────┘
                          ↕ (同步)
┌─────────────────────────────────────────────────────────┐
│                  浏览器端 (Browser)                     │
│  - IndexedDB本地存储                                    │
│  - Service Worker离线支持                              │
│  - 本地缓存策略                                         │
│  - 增量同步                                             │
└─────────────────────────────────────────────────────────┘
```

### 1.2 核心功能模块

#### 1.2.1 本地数据管理
- **SQLite数据库**: 结构化数据存储
- **文件系统**: 代码、文件、工作流定义
- **本地缓存**: 热数据缓存，减少磁盘I/O

#### 1.2.2 隐私保护
- **敏感数据加密**: AES-256加密存储
- **API密钥管理**: 本地加密，不上传
- **代码/文件本地处理**: 敏感内容不离开本地

#### 1.2.3 同步客户端
- **增量同步引擎**: 只同步变化的数据
- **冲突检测**: 检测本地-云端冲突
- **冲突解决**: 支持多种解决策略
- **离线队列**: 离线时缓存操作

#### 1.2.4 性能优化
- **本地索引**: 快速查询
- **智能预加载**: 预测性加载
- **后台同步**: 不阻塞主线程
- **批量操作**: 减少网络往返

## 2. 数据流架构

### 2.1 读取流程

```
用户请求
  ↓
检查本地缓存 (L1)
  ↓ (缓存命中)
返回数据
  ↓ (缓存未命中)
查询本地SQLite (L2)
  ↓ (本地命中)
更新缓存，返回数据
  ↓ (本地未命中)
检查离线模式
  ↓ (在线)
从云端同步 (L3)
  ↓ (离线)
返回离线提示
```

### 2.2 写入流程

```
用户写入
  ↓
验证数据
  ↓
检查是否敏感数据
  ↓ (敏感)
本地加密存储
  ↓ (非敏感)
本地存储
  ↓
更新本地缓存
  ↓
检查网络连接
  ↓ (在线)
加入同步队列
  ↓ (离线)
加入离线队列
  ↓
后台同步处理
```

### 2.3 同步流程

```
同步触发
  ↓
获取本地变更集
  ↓
获取云端变更集
  ↓
检测冲突
  ↓ (有冲突)
执行冲突解决策略
  ↓ (无冲突)
合并变更
  ↓
上传本地变更
  ↓
下载云端变更
  ↓
更新本地数据库
  ↓
更新缓存
  ↓
发送同步完成事件
```

#### 加密管理表
- `encrypted_data`: 加密数据存储

### 3.2 索引策略

- 主键索引: 快速查询

- 复合索引: 常见查询模式

## 4. 同步策略

### 4.1 增量同步

基于时间戳和版本号的增量同步：
- 记录每条数据的最后修改时间
- 只同步修改时间之后的数据
- 支持断点续传

### 4.2 冲突检测

三种冲突类型：
1. **更新冲突**: 同一数据被本地和云端同时修改
2. **删除冲突**: 本地删除但云端修改
3. **创建冲突**: 本地和云端同时创建相同ID的数据

### 4.3 冲突解决策略

- **Last-Write-Wins (LWW)**: 最后修改时间优先
- **Local-Wins**: 本地优先
- **Cloud-Wins**: 云端优先
- **Manual**: 用户手动选择
- **Merge**: 智能合并（适用于某些数据类型）

### 4.4 离线支持

- 离线时所有操作加入离线队列
- 恢复连接时自动同步
- 支持离线操作的本地验证

## 5. 安全设计

### 5.1 加密策略

- **传输加密**: TLS/HTTPS
- **存储加密**: AES-256-GCM
- **密钥管理**: 本地密钥存储，支持密钥轮换

### 5.2 敏感数据分类

1. **API密钥**: 永不上传，本地加密存储
2. **代码内容**: 可选加密，支持本地处理
3. **个人信息**: 加密存储
4. **执行日志**: 可选加密

### 5.3 访问控制

- 基于角色的访问控制 (RBAC)
- 数据级别的访问控制
- 审计日志记录

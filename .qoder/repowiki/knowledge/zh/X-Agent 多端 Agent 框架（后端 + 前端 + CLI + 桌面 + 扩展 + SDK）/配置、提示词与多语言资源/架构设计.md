本模块为纯数据/声明式资源目录，不含可执行代码，由后端 `backend/app/core` 下的解析器（如 `llm/profiles.py`、prompt_manager）在启动时加载：
- `config/`：企业版功能开关、RBAC 角色、审计策略、订阅计划与用量计费、数据库/缓存/监控等运行时配置；`model_profiles.yaml` 作为智能路由与 Token 计费的单一事实来源，通过环境变量 `XAGENT_LLM_MODEL_PROFILES_PATH` 覆盖路径，缺失时回退到 selector 内建默认并记录 warning。
- `prompts/`：按 scope 分目录的 Markdown 提示词，每个文件以 YAML frontmatter 声明 id/name/version/purpose/variables 等元数据，由 `prompt_manager.initialize()` 扫描加载，支持语义化版本与变量替换，供 system/roles/tools/recovery/memory/navigation/marketplace 各阶段消费。
- `templates/`：Docker Compose 与 Kubernetes Deployment 清单，用于一键拉起 postgres/pgvector、redis、neo4j、milvus+etcd+minio、backend/celery-worker/celery-beat/frontend 等依赖服务。
- `locales/`：按语言拆分的 JSON 翻译键值表（en/es/ja/ko/zh），供前端 i18n 框架按当前 locale 动态加载。
依赖方向单向：本模块仅被 `backend/app/core/*` 读取，不反向依赖任何 Python 包。

- 配置统一通过 `backend.app.settings.get_settings()` 获取，使用 `XAGENT_` 前缀的环境变量与 `.env` 文件加载，禁止在各处硬编码配置值。
- 跨模块共享的服务实例（memory/trace/runs/audit/browser/desktop/tool_execution 等）集中在 `dependencies.py` 中以 `@lru_cache` 工厂函数暴露，API 路由通过 FastAPI `Depends` 消费而非直接 import 单例。
- 可插拔后端（memory_backend、trace_backend、embedding_backend、admin_store_backend 等）采用字符串开关 + `build_xxx` 工厂函数的策略模式，在 `dependencies.py` 中根据 settings 动态返回对应实现。
- API 路由文件只负责参数解析与调用 service/core 层，错误统一抛出 `backend.app.api.errors.XAgentAPIError` 并由 `main.py` 中的异常处理器收敛为 JSON 响应。
- 中间件以类形式定义（如 `CSRFProtectionMiddleware`、`TenantIsolationMiddleware`），在 `main.py` 的 `app.add_middleware` 或 `@app.middleware("http")` 装饰器中集中注册，保持请求处理管线单一入口。
- 对外部可选依赖（prometheus_client、qdrant-client、langfuse 等）采用 try/except ImportError 或 TYPE_CHECKING 惰性导入，缺失时降级到内存/日志告警，保证应用无依赖也能启动。

模块以 `app/main.py` 为唯一 ASGI 应用入口（`uvicorn backend.app.main:app`），在进程启动时集中挂载中间件栈（CORS → CSRFProtectionMiddleware → MetricsMiddleware → TenantIsolationMiddleware → 自定义 rate_limit / request_logging / security_headers / tenant_isolation http middleware），并通过 `app.include_router(...)` 将 `backend/app/api/` 下每个领域文件暴露为 `/api/v1/*` 路由；`app/web.py` 仅做向后兼容重导出。

- 配置层：`settings.Settings`（pydantic-settings，`XAGENT_` 前缀 + `.env`）通过 `get_settings()` 缓存，并在生产模式对 sqlite/memory/jsonl 存储、默认密钥、CORS wildcard 执行 fail-fast 校验。
- 依赖注入：`dependencies.py` 提供 `@lru_cache` 的全局工厂（`get_memory`/`get_trace_store`/`get_run_store`/`get_audit_store`/`get_browser_store` 等），按 `memory_backend`/`trace_backend` 等开关选择内存、JSONL、Postgres、Qdrant 实现，供 API 路由通过 FastAPI `Depends` 消费。
- 核心能力位于 `core/` 子包（agent、agent_v2、llm、memory、sandbox、mcp、hooks、parallel、sso、analytics、middleware、config 等），API 路由仅编排调用，不承载业务逻辑；`services/` 封装浏览器自动化、向量检索、可观测性导出等外部服务。
- 启动/关闭钩子：`startup_event` 初始化 MCP 管理器、Hooks 配置、sandbox worker；`shutdown_event` 反向清理；`/health`、`/ready` 分别作为 liveness/readiness probe，后者遍历所有 store getter 并报告可选集成（qdrant/browser/langfuse）的 ok/degraded 状态。
- 安全边界：CSRF 中间件显式豁免签名 webhook（feishu、telegram）、Bearer/API-Key 认证请求；tenant isolation 中间件在非 admin principal 下校验 `tenant_id` 参数；`require_api_key` 全局开关由 `request_logging_middleware` 在入口处拦截。
- 辅助入口：`cli.py` 提供 `xagent` Typer CLI（run/chat/tools/config/logs/admin），`local/` 提供本地开发数据库/加密/迁移脚本，`plugins/` 定义插件运行时与示例，`migrations/*.sql` 存放 DDL。

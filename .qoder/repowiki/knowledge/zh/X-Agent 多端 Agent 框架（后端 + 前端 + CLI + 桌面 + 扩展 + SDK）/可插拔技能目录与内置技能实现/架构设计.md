本模块是 X-Agent 技能生态的“插件仓库 + 文档”层，遵循以下约定：
- 每个技能一个子目录（如 `code-review-skill/`、`data-analysis-skill/`），必须包含 `SKILL.md`（说明）与 `main.py`（导出 `SkillImplementation` 类），由 `backend.app.core.skills.SkillLoader` 在默认扫描路径 `skills/` 与 `custom-skills/` 下自动发现。
- 技能通过继承 `backend.app.core.skills.Skill` 并实现 `metadata`、可选的 `parameters_schema`、`validate`、`execute` 四个钩子来声明能力；返回统一 `SkillResult(success, data, error)` 结构，失败显式返回而非抛异常。
- 运行时集成入口为 `backend/app/core/skill_agent_adapter.py`，对外暴露 `register_skills_into_tool_registry` / `list_skill_tools` / `build_skill_tool_handler`，将已加载技能注册进 AgentLoop 的 `ToolRegistry`，工具名前缀固定为 `skill__`。
- 租户/用户隔离通过 `context_defaults` 注入 `_tenant_id` / `_user_id` 保留参数完成，不依赖 ToolRegistry 的 RunContext。
- `RUNTIME_INTEGRATION.md` 作为 P1-11 交付物的集成波接线指南，同时记录 legacy `skills_api.py`（未挂载）与 P1-12 插件系统边界，明确 MCP 协议尚未实现。
- 依赖方向单向：本模块仅依赖 `backend.app.core.skills` 契约，不被核心运行时反向引用，属于被加载的“叶子插件”。

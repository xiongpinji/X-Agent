- 每个技能目录以 `SKILL.md` + `main.py` 组织，`main.py` 必须导出名为 `SkillImplementation` 的类且继承自 `backend.app.core.skills.Skill`。
- 技能通过类属性 `parameters_schema` 声明 JSON Schema 供 LLM 工具调用，并通过 `validate` 做入参校验、`execute` 返回 `SkillResult(success=..., data=..., error=...)` 三元组。
- 错误路径一律返回 `SkillResult(success=False, error=...)` 显式降级，禁止抛出未捕获异常让上层静默吞错。
- 内置技能仅使用 Python 标准库（`ast`、`csv`、`statistics`、`pathlib`），不引入第三方依赖，保证零安装成本。
- 每个 `main.py` 末尾附带 `if __name__ == "__main__":` 冒烟脚本，可直接 `python skills/<skill>/main.py` 独立验证。

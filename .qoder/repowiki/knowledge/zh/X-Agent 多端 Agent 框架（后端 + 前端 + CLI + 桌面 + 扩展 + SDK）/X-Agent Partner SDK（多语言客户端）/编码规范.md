- 每个 SDK 顶层常量 `VERSION` 固定为 `0.2.0-alpha`，并通过注释明确与 Python `__version__` 保持同步，作为跨语言版本单一事实源。
- HTTP 客户端构造时统一设置 `Authorization: Bearer <apiKey>`、`Content-Type: application/json` 与 `User-Agent: xagent-partner-sdk/<VERSION>` 三个默认请求头。
- 所有网络请求集中在单个 `makeRequest`/`_make_request` 方法中，统一实现 429 重试（优先读 `Retry-After` 头）、5xx 指数退避、401/404/其他 4xx 错误分类抛出专用异常。
- 异常体系采用基类 + 子类分层：`PartnerAPIError`/`PartnerAPIException` 为基类，派生出 `PartnerAuthError`(401)、`PartnerNotFoundError`(404)、`PartnerRateLimitError`(429)。
- 后端错误体兼容 FastAPI 两种形状：优先取 `detail` 字段，回退到 `error.message`，再回退到字符串化后的原始 body。
- 列表端点返回裸 JSON 数组而非 `{items:[...]}` 包装对象，SDK 侧在反序列化前做 `Array.isArray` / `constructCollectionType` 适配。

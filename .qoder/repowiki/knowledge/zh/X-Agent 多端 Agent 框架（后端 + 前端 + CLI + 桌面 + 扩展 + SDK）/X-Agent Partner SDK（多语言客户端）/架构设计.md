模块按语言划分为四个独立子目录 go/、java/、javascript/、python/，每个子目录是一个自包含的包，彼此无共享代码，仅通过统一的 REST 语义约定对齐。

- 分发形态：全部以源码 / 本地构建产物形式分发，未发布到任何公共包仓库；Go 使用 `go.mod` + `replace` 指令引用，Python 通过 `pyproject.toml` 打包 wheel/sdist，JavaScript 通过 `package.json` + `tsc` 编译到 `dist/`，Java 直接拷贝 `.java` 源码引入。
- 统一入口类：各语言均暴露一个 `PartnerClient`（Go: `xagent.NewPartnerClient`，JS: `new PartnerClient()`，Python: `PartnerClient(...)`，Java: `new PartnerClient(...)`），构造时接收 `apiKey`、可选 `baseUrl`、`timeout`、`maxRetries`。
- 请求层抽象：每个 SDK 内部实现一个 `makeRequest`/`_make_request` 核心方法，集中处理 Bearer Token 注入、429 重试（读取 Retry-After）、5xx 指数退避、401/404/其他 4xx 异常映射以及 204 No Content 空响应兼容。
- 业务域划分：所有 SDK 将方法按 Partner Management、API Key Management、Webhook Management、Usage & Analytics、Support Tickets、Dashboard & Health、Webhook Verification 七大块组织，REST 路径统一为 `/api/v1/partners/{partner_id}/...`。
- Webhook 签名验证：各语言提供静态 `verifyWebhookSignature`，基于 HMAC-SHA256 并采用常量时间比较（Go `hmac.Equal`、Java `MessageDigest.isEqual`、JS `crypto.timingSafeEqual`、Python `hmac.compare_digest`）。
- 版本一致性：各语言源文件顶部显式声明 `VERSION = "0.2.0-alpha"`，并通过注释标注与 Python `__version__` 保持一致，作为跨语言版本的单一事实来源。

所有 SDK 均未发布到线上包仓库，需本地安装：
- Python: `pip install ./sdks/python` 或 `python -m pip wheel ./sdks/python --no-deps -w dist`
- JavaScript: `cd sdks/javascript && npm install && npm run build`，再以 `npm install ./sdks/javascript` 或 `npm pack` 引入
- Go: 在宿主项目 `go.mod` 中添加 `replace github.com/xagent/partner-sdk-go => /path/to/X-Agent/sdks/go`
- Java: 直接拷贝 `java/PartnerClient.java` 与 `java/PartnerAPIException.java` 到项目并保持 `io.xagent.partner` 包结构，添加 Jackson 依赖。

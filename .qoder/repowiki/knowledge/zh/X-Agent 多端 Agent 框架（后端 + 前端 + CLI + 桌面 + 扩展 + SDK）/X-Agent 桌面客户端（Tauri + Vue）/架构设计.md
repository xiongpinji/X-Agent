模块采用 Tauri 1.5 双进程架构：
- Rust 后端（`src/`）：`main.rs` 通过 `tauri::Builder` 注册 `generate_handler!` 暴露 IPC 命令，集中挂载于 `commands/{file,agent,api,settings,window}.rs`；全局状态由 `state.rs` 中的 `AppState`（`Arc<AppState>` 注入 `app.manage`）承载，内部用 `tokio::sync::RwLock<bool>` 保护 `backend_connected` / `agent_running` 标志；`db.rs` 使用 sqlx+SQLite 持久化，`config.rs` 加载配置，`ipc.rs` 异步连接外部后端，`tray.rs` 实现系统托盘菜单，`security.rs` 封装 AES-GCM 加解密。
- Vue 前端（`frontend/`）：Vite 5 + Vue 3 + vue-router + Element Plus + Pinia，路由在 `router/index.ts`，页面位于 `views/`，通过 `@tauri-apps/api` 调用 Rust 侧命令。
- 构建与打包：`Cargo.toml` 声明 `tauri-build` build-dependency，`build.rs` 调用 `tauri_build::build`；`tauri.conf.json` 指定 `beforeDevCommand: npm --prefix ../frontend run dev`、`distDir: ../frontend/dist`，开发时 Vite 在 3000 端口热重载，发布时先 `npm run build` 再打包为 MSI/NSIS；`icons/` 下提供多分辨率图标与 `.icns/.ico`。
- 依赖方向：前端 → Tauri invoke → Rust commands → state/db/ipc/tray，Rust 侧仅通过 `tauri::AppHandle` 回调窗口与托盘事件，不反向依赖前端。

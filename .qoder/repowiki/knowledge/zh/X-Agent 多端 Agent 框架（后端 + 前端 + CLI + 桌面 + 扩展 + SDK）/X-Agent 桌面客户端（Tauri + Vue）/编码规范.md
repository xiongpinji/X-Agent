- IPC 命令按功能域拆分为 `src/commands/{file,agent,api,settings,window}.rs` 子模块，统一在 `main.rs` 中通过 `generate_handler!` 宏集中注册。
- 共享可变状态集中在 `state.rs` 的 `AppState` 结构体中，以 `Arc<RwLock<T>>` 包装并通过 `app.manage(state)` 注入到 Tauri 应用上下文。
- 所有对外部系统的 I/O（数据库初始化、后端连接、托盘/快捷键设置）均在 `setup_app` 钩子内以 `tauri::async_runtime::spawn` 异步执行，避免阻塞主线程。
- 错误处理统一使用 `anyhow::Result` 配合 `thiserror`，并在关键路径上通过 `log::error!` 记录失败原因。

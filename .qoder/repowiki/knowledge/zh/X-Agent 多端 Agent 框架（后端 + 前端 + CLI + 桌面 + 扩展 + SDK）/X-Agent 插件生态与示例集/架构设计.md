本模块是 X-Agent 的插件仓库，按用途分为三类：
- 传统插件（`automation-plugin/`、`data-processor-plugin/`、`github-plugin/`）：仅含 `plugin.manifest.json`，通过 `entry_point` 指向 Python 包入口，由宿主加载；manifest 描述依赖、权限、风险等级等元数据。
- MCP 风格插件（`database-mcp/`、`filesystem-mcp/`、`github-mcp/`）：每个子目录是一个独立 Python 包，包含 `manifest.json`（schema_version=1.0，声明 `type: mcp-plugin`、`capabilities`、`permissions`、`configuration`、`tools`、`resources`、`security.sandbox` 等）和 `main.py` 中实现的 `*Plugin` 类（如 `DatabasePlugin`、`FileSystemPlugin`、`GitHubPlugin`），由宿主根据 manifest 动态导入并实例化。
- 开发辅助（`examples/`、`templates/`）：`hello_world_plugin.py` 与 `template_plugin.py` 定义了统一的插件基类约定——类属性 `name/version/description/author/license`，生命周期方法 `initialize/register/cleanup`（均为 async），以及通过 `self.tools` 字典注册工具函数，供开发者直接复制扩展。

依赖方向单向：宿主 → 读取各子目录 manifest → 解析 capabilities/permissions/configuration → 动态 import entry_point 指定的 module/class → 调用生命周期钩子完成注册。

模块采用多入口 SPA 架构：`vite.config.ts` 通过 Rollup `input` 定义四个 HTML 入口——`index.html`（主应用）、`chat.html`、`console.html`（统一控制台）、`startup.html`，分别挂载到不同页面。

- 入口层：`src/main.tsx` 注入 PerformanceObserver 监控 Core Web Vitals 并懒加载非关键资源；`src/App.tsx` 使用 `react-router-dom` 配合 `React.lazy` 对 Dashboard/Chat/Tasks/Tools/Memory 等页面进行路由级代码分割。
- 统一控制台子应用：`src/console/ConsoleShell.tsx` 作为独立 Shell，内部用 `switch(state.activePage)` 渲染 overview / execution / tools / memory / organization / marketplace / navigation / audit / workflow 等数十个页面组件，并通过 `useConsoleRealtimeSync` hook 以 `/api/v1/workbench` bootstrap + `/api/v1/messages/stream` SSE 拉取数据，再经 `state/consoleContext.tsx` + `consoleReducer.ts` 驱动全局状态，各业务域由 `*Selectors.ts` 文件按领域拆分选择器。
- 组件分层：`src/components/ui/` 为无业务语义的基础 UI 原子组件（Button/Card/DataTable 等），`src/components/feedback/` 和 `src/components/streaming/` 是面向反馈仪表盘与 SSE 可视化的高阶组件，其余如 `Layout.tsx`、`StreamingOutput.tsx` 属于页面级布局/交互组件。
- 服务层：`src/services/apiClient.ts` 封装 `fetch` 请求（带 AbortController 超时与错误解析），`src/services/sseClient.ts` 处理 Server-Sent Events，`src/services/feedback.ts` 暴露反馈 API，`src/services/api.ts` 导出单例供上层消费。
- 状态管理：除 console 自管 reducer 外，主应用使用 `zustand`（`store/appStore.ts`、`store/agentStore.ts`）+ `@tanstack/react-query` 做服务端缓存；i18n 通过 `src/i18n/context.tsx` + `I18nProvider` 包裹根节点，翻译文件位于 `i18n/translations/*.json`。
- 构建与部署：`Dockerfile` 将 `dist/` 产物作为静态资源输出；`public/sw.js` + `manifest.json` 启用 PWA；Tailwind + PostCSS + Lightning CSS 完成样式编译；ESLint/Prettier 保证代码风格。

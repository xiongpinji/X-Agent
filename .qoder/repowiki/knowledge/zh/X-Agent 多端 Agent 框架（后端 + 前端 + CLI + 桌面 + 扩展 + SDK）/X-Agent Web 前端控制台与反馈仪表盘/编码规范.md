- 页面路由采用 `react-router-dom` 的 `lazy(() => import(...))` 模式，配合顶层 `<Suspense fallback={<PageLoader/>}>` 实现路由级代码分割。
- API 调用集中在 `services/apiClient.ts` 的 `APIClient` 类中，每个后端接口对应一个方法，统一通过私有 `request<T>` 封装 `fetch` + `AbortController` 超时与 JSON 反序列化。
- 统一控制台的状态按业务域拆分为独立的 `*Selectors.ts` 文件（如 `executionControlSelectors.ts`、`toolsCenterSelectors.ts`），并在 `ConsoleShell.tsx` 中以 `selectXxxData(state)` 形式集中订阅。
- 控制台内页切换通过 `dispatch({ type: 'page/set', payload: '<key>' })` 修改 `activePage`，再由 `renderPage()` 中的 `switch(state.activePage)` 映射到具体页面组件。
- 国际化文本通过 `src/i18n/context.tsx` 提供的 `I18nProvider` 注入，翻译键值按语言拆分为 `translations/{ar,en,es,ja,ko,zh}.json` 文件。
- Vite 别名统一使用 `@/`、`@components`、`@pages`、`@services`、`@store`、`@hooks`、`@utils`、`@i18n` 等路径前缀，禁止相对深层路径引用。

- 所有运行时模块以 ES6 class 封装（BackgroundWorker、MCPClient、ContentScriptManager、PopupManager、TabGroupManager、StorageManager），并提供 `initialize()` 生命周期方法集中注册事件监听。
- 跨脚本通信统一采用 `{ type, payload }` 消息信封，background 内部通过 `switch(type)` 分发到对应 async 方法，错误一律返回 `{ success: false, error }` 结构。
- 对 chrome.* API 的调用均包裹 try/catch 并以 `{ success, result/error }` 形式回传，避免未捕获异常导致 Service Worker 崩溃。
- 可持久化状态（会话、设置）统一经由 StorageManager 读写，background 在执行动作后主动将 action 追加到 `activeSession.actions` 并落盘。
- 日志输出统一以 `[X-Agent]` 前缀开头，便于在 DevTools Console 中过滤扩展相关输出。

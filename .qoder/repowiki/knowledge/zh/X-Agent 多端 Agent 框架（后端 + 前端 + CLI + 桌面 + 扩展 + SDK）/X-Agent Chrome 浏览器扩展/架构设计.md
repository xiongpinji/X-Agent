扩展遵循 MV3 标准，按运行环境划分为四个独立入口：
- `background.js`（Service Worker）：作为中央调度器，集中处理来自 content/popup/commands 的消息路由，维护活跃会话与元素引用表，并委托给三个模块类——`MCPClient`（通过 `chrome.runtime.connectNative('com.xagent.extension')` 与桌面端建立原生消息通道）、`TabGroupManager`、`StorageManager`。
- `content.js`（Content Script，`document_start` 注入到所有 frame）：在页面上下文中执行 DOM 操作（查询元素、填充表单、点击、截图），并通过 `injected.js`（web_accessible_resources）获得更深层的 DOM 访问。
- `popup.html/js/css`：用户交互入口，通过 `chrome.runtime.sendMessage` 与 background 通信。
- `manifest.json` 声明权限（activeTab/scripting/webRequest/tabs/storage/webNavigation/contextMenus/offscreen/nativeMessaging）与快捷键命令。
依赖方向单向：popup/content → background → (mcp-client / tab-group-manager / storage-manager)；测试层使用 Jest + jsdom，由 `tests/run-tests.js` 统一驱动 unit/integration/security 三类用例。

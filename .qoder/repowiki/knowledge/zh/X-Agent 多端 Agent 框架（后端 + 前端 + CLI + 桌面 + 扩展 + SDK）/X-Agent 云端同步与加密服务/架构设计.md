本模块为纯 Python 实现，由两个独立的服务脚本组成：
- `sync_service.py`：核心同步引擎，包含 `VectorClock`（因果关系建模）、`SyncOperation`/`VersionSnapshot`/`ConflictRecord`/`SyncState` 等 Pydantic 模型，以及 `ConflictDetector`（基于向量时钟并发检测）和 `ConflictResolver`（支持 LWW、CRDT 递归字典合并、人工审核三种策略），对外暴露 `SyncService.submit_operation` / `resolve_conflict` / `get_version_history` / `restore_version` / `get_sync_status` 等方法。
- `encryption_service.py`：加密子系统，`CryptoUtils` 封装 RSA-4096 OAEP-SHA256 与 AES-256-GCM 原语，`EncryptionService` 以主密钥派生一次性 AES 密钥进行信封加密，并提供密钥轮换/撤销；`ZeroKnowledgeProofService` 基于 Schnorr 简化协议生成/验证零知识证明。
- 依赖方向单向：`sync_service` 通过 `SyncOperation.encryption_key_id` 字段引用加密层，但当前代码中两者未直接 import，实际集成应通过 API 或共享模型完成。
- 无 Web 框架绑定，所有类均可作为库被 FastAPI 或其他 HTTP 层调用；`requirements.txt` 仅声明运行时依赖，无构建脚本。

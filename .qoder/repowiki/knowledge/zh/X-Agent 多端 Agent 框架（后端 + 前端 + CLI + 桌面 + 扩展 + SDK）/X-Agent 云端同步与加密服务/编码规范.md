- 所有持久化/传输数据结构统一使用 Pydantic BaseModel 定义，并通过 Field(default_factory=...) 注入 UTC 时间戳与 UUID，避免在构造处重复赋值。
- 每个 .py 文件按“数据模型 → 工具类 → 服务类 → example_usage”四段式组织，并用 `# === ... ===` 注释分隔区块。
- 日志通过 `logging.getLogger(__name__)` 获取 logger，并在关键路径（encrypt/decrypt、submit_operation、resolve_conflict、rotate_key）前后记录 INFO/WARNING/ERROR 级别消息。
- 算法参数集中定义在 CryptoUtils 类常量（如 RSA_KEY_SIZE=4096、AES_KEY_SIZE=32、GCM_TAG_SIZE=16），而非魔法数字散落各处。
- 错误处理采用抛出 ValueError 并附带 key_id/entity_id 等上下文字符串的方式，便于上层捕获后返回结构化错误响应。

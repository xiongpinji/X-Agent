- 示例脚本采用 `async def example_<场景>()` + `async def main()` 结构，通过 `if __name__ == "__main__":` 调用 `asyncio.run(main())` 作为唯一入口。
- 外部服务凭据一律通过 `os.getenv("...")` 读取，未设置时打印警告并跳过对应用例，保证离线可运行。
- 基准场景以 `config.py` 中 `BENCHMARK_SCENARIOS` 字典集中声明（name/complexity/tool_calls/iterations/target_time），被测脚本仅消费该配置而不硬编码参数。
- 基准输出遵循固定命名约定：`unit_benchmark_results.json`、`integration_benchmark_results.json`、`PERFORMANCE_BENCHMARK_REPORT.md`、`BENCHMARK_COMPARISON.txt`，全部写入 `benchmarks/results/` 目录。

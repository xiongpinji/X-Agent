本模块由两个并列子目录组成，均不向 `backend` 以外的上层暴露接口。

- `examples/`：4 个独立可执行的 Python 脚本，直接 import `backend.app.core.llm_providers`、`backend.app.services.browser`、`backend.app.core.execution.OptimizedExecutionManager` 等内部包演示用法；每个脚本以 `async def example_*` + `main()` 组织，通过环境变量（如 `OPENAI_API_KEY`、`ANTHROPIC_API_KEY`、`OLLAMA_BASE_URL`）控制在线能力开关并优雅降级。
- `benchmarks/`：基于 asyncio 的基准套件，入口为 `run_benchmarks.py`，按顺序编排三类组件：
  - 被测对象：`agent_v2_benchmark.py`（单元级）、`agent_v2_integration_benchmark.py`（集成级）、`wave_a_load_benchmark.py`（负载型）；
  - 配置常量：`config.py` 中的 `BenchmarkConfig` dataclass、`BENCHMARK_SCENARIOS` 字典、`METRIC_THRESHOLDS` 阈值表；
  - 产出层：`analyzer.py` 采集 timing/memory/CPU 指标，`report_generator.py` 生成 Markdown 报告与对比表格，结果统一落盘到 `benchmarks/results/`（含 JSON 与 `.log`）。
依赖方向单向指向 `backend/app/core` 与 `backend/app/services`，benchmark 之间通过 `results/*.json` 文件交换数据而非共享内存。

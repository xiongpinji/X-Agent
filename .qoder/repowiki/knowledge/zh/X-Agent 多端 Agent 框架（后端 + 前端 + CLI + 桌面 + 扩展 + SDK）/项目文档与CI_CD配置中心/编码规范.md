- 文档以中文为主、英文文件以 `_EN` 后缀区分（如 `README_EN.md`、`FAQ_EN.md`、`USER_GUIDE_EN.md`），同一主题的中英双语文档并存。
- 管理员与企业能力相关文档统一使用大写前缀命名（`ENTERPRISE_*`、`SSO_*`、`SUBSCRIPTION_*`、`SECURITY_*`），便于在目录中快速识别。
- 开发者侧的历史交付物集中归档于 `developer/reports/`，文件名采用 `AGENT_XX_*` 或 `PHASE*_COMPLETION_REPORT.md` 等编号化命名，与 `developer/reports/INDEX.md` 索引配合。
- CI/CD 相关文档围绕单一入口 `.github/README.md` 组织，所有子指南通过该 README 的导航表格聚合，避免散落。

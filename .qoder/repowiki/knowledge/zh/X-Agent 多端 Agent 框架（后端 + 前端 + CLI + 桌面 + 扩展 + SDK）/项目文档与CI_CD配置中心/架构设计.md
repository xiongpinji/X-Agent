本模块由两个并列的文档子域组成，均无可执行代码：
- `docs/` 按读者角色收敛为四个分册：`concepts/`（架构设计、功能特性、Mermaid 架构图、规划）、`operations/`（安装部署、监控性能、故障排除）、`admin/`（安全、SSO、企业版、订阅计费、审计）、`developer/`（API/SDK/插件开发、教程、贡献指南、历史报告归档）。根级 `README.md` 提供总索引与快速入口，并记录了 2026-07-20 对 320+ 篇散乱文档的收敛迁移。
- `.github/` 存放 GitHub Actions 工作流 YAML 与配套的 CI/CD 文档（`QUICK-START.md`、`CI-CD-GUIDE.md`、`DEPLOYMENT-GUIDE.md`、`GITHUB-ACTIONS-BEST-PRACTICES.md`、`CI-CD-FLOWCHARTS.md`、`CI-CD-SUMMARY.md`），并通过 `ruff-blocking-baseline.txt` 固定 Ruff 基线版本；`ISSUE_TEMPLATE/` 与 `PULL_REQUEST_TEMPLATE.md` 定义协作模板。
依赖方向单向：源码 → 本文档，本文档之间通过相对 Markdown 引用互链，不引入外部构建产物。

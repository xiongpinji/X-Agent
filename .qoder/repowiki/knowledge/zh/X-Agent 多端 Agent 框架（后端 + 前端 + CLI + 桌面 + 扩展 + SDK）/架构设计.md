根目录作为跨子模块的编排层，不承载业务逻辑，仅定义统一的契约与启动路径：
- 版本与依赖：`pyproject.toml` 是仓库唯一版本来源（注释明确），并通过 `[project.scripts]` 暴露 `xagent`、`xagent-workflow-worker`、`xagent-desktop` 等可执行入口，供 CLI、desktop_app、backend 共享。
- 运行时编排：`docker-compose.yml` 将 backend API、asyncio workflow worker、PostgreSQL、Redis、Qdrant、Neo4j 组装为本地开发环境；`monitoring/docker-compose.monitoring.yml` 由 `make monitor-*` 调用，拉起 Prometheus/Grafana/ELK/Jaeger 全栈。
- 构建与质量门禁：`Makefile` 提供 `build`、`ci`、`test-unit/integration/e2e/performance`、`lint/format/type-check/security` 等统一目标，所有子模块共用同一套 ruff/black/isort/mypy/bandit/pip-audit 配置。
- 代码提交门禁：`.pre-commit-config.yaml` 在 commit 阶段统一触发格式检查、类型检查与安全扫描，约束 backend/cli/sdks/tests 等所有 Python 子模块。
- 前端与扩展：frontend 与 chrome_extension 通过环境变量 `XAGENT_CORS_ORIGINS` 与后端解耦，桌面端通过 Tauri 代理到后端 HTTP API，三者共享同一份 `config_prompts_templates` 中的提示词与 i18n 资源。
- 测试与基准：`tests_and_data` 通过 pytest marker（unit/integration/contracts/e2e/performance）被 `Makefile` 统一调度，`examples_and_benchmarks` 与 `locustfile.py` 复用同一组 `XAGENT_*` 环境变量驱动。

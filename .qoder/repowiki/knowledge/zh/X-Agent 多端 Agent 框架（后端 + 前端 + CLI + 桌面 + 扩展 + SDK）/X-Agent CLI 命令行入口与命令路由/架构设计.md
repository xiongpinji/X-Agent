- `cli/main.py` 创建顶层 `Typer(app)`，通过 `@app.callback()` 解析 --api-url/--api-key/--mode/--output 等全局参数，调用 `cli.config.load_config` 生成 `CLIConfig` 并写入 `cli.state.set_current_config`。
- 所有子命令模块（`commands/agent_cmd.py`、`tools_cmd.py`、`workflow_cmd.py`、`init_cmd.py`、`hooks_cmd.py`、`approvals_cmd.py`、`github_cmd.py`、`gateway_cmd.py`）各自暴露一个 `*_app` 实例，由 `commands/__init__.py` 汇总导出，再由 `main.py` 通过 `app.add_typer(...)` 统一挂载为 `xagent <group>` 子命令。
- 子命令不直接依赖 `main.py`，而是通过 `cli.state.get_current_config()` 读取共享配置，避免循环导入；需要网络交互时再按需 `from cli.client import create_client` 获取 HTTP/本地双模式客户端。
- 独立命令（health、config_show、repl）直接在 `main.py` 中用 `@app.command()` 定义，复用同一套配置与输出通道（`cli.console.print_info/print_error`）。

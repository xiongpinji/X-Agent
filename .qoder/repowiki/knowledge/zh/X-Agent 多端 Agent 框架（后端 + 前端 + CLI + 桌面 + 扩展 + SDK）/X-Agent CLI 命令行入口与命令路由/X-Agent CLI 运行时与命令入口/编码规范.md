- 所有对外暴露的客户端方法均为 async，并在 docstring 中统一声明可能抛出的 ConnectionError/AuthError/APIError 异常类型。
- 配置项通过 Pydantic Field 的 Literal 类型约束取值域（如 mode: Literal["http", "local"]、output_format: Literal["rich", "json", "plain"]），并用 field_validator 做数值校验。
- 输出函数遵循统一的三态分支：当 config.output_format == "json" 时返回纯 JSON，== "plain" 时打印无样式文本，否则走 rich Console 带颜色/语法高亮。
- 需要访问当前配置的子命令一律通过 `cli.state.get_current_config()` 获取，而非直接 import cli.main，以此规避循环导入。
- 客户端错误处理采用「底层异常 → 自定义 XAgentCLIError 子类」的映射策略，HTTP 层将 httpx.ConnectError/TimeoutException 转为 ConnectionError，401/403 转为 AuthError，其余 ≥400 转为 APIError。

模块按职责拆分为六个平铺文件，形成「入口 → 配置 → 状态 → 客户端 → 输出 → REPL」的单向依赖链：
- `main.py` 是 Typer 应用入口，定义全局选项（--api-url/--api-key/--mode/--output/--version）并通过 `@app.callback` 在解析参数后调用 `load_config` + `set_current_config`，再挂载 `cli.commands.*` 下的子应用；同时内联 `health`、`config_show`、`repl` 三个独立命令。
- `config.py` 使用 pydantic-settings 的 `BaseSettings` 定义 `CLIConfig`，通过重写 `settings_customise_sources` 仅以显式传入的 init 值作为来源，由 `load_config` 自行实现「TOML 文件 < 环境变量 XAGENT_* < 命令行参数」的合并优先级，并支持读写 `~/.xagent/config.toml`。
- `state.py` 暴露 `_current_config` 全局变量及 `get/set_current_config`，专门用于打破 `cli.main` 与 `cli.commands.*` 之间的循环导入，使子命令能读取已解析的配置。
- `client.py` 定义 `BaseClient` 抽象接口及其两个实现：`HTTPClient`（基于 httpx.AsyncClient，统一封装 /api/v1/* 端点并将 HTTP 错误映射为 `ConnectionError`/`AuthError`/`APIError`）、`LocalClient`（直接 import `backend.app.dependencies.get_agent` 进行本地执行，未实现的方法抛出 `NotImplementedError`），并由工厂函数 `create_client(config)` 根据 `config.mode` 选择实例。
- `console.py` 基于 rich 提供 `print_success/error/warning/info/json/table/code` 等格式化输出函数，内部维护一个全局 `Console` 单例，依据 `config.output_format` 在 rich/json/plain 三种格式间切换。
- `repl.py` 基于 prompt_toolkit 实现 `XAgentREPL` 类，提供命令历史（`~/.xagent/repl_history`）、自动补全和 run/agents/tools/workflows/status 等内置命令，通过 `asyncio.run(repl.run())` 启动事件循环。
依赖方向严格自上而下：main → config/state/client/console/repl，子命令包 `cli.commands` 反向通过 state 读取配置，避免环入。

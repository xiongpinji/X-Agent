- 所有外部服务均以 Docker image 版本固定（如 prom/prometheus:v2.48.0、grafana/grafana:10.2.0），避免隐式升级导致行为漂移。
- 配置与数据分离：YAML 配置通过只读 volume 映射到容器内标准路径（如 `/etc/prometheus/prometheus.yml`、`/etc/alertmanager/alertmanager.yml`），数据落盘统一使用命名卷。
- 每个关键服务在 compose 中声明 healthcheck，并使用 `depends_on ... condition: service_healthy` 建立启动顺序依赖。
- Prometheus scrape job 统一标注 `service` 与 `component` 标签，便于按组件维度过滤与告警。
- 告警规则按业务域分组（api/agent/database/cache/system/tools/workflow/vector-db/prometheus），每条均附带 severity/component 标签与 runbook_url 注解。
- Logstash 处理流程按 input.type 分支组织 filter/output，对 xagent-app/error/audit 三类日志分别提取字段并写入不同 ES index。

- 每个有状态组件（postgres/redis/qdrant/neo4j）均暴露 `enabled` + `image` + `storage` + `resources` + `terminationGracePeriodSeconds`/`preStopSleepSeconds` 的统一 values 结构，并在 `_helpers.tpl` 中提供对应的 `xagent.<component>Host` 模板以统一解析集群内 Service 或外部 host。
- 所有 Deployment 采用 RollingUpdate 策略（maxSurge=1, maxUnavailable=0），并为 API/Worker/Beat 分别设置递增的 `terminationGracePeriodSeconds`（API≥90s、Worker≥120s、Beat≥60s）配合容器 preStop sleep 实现有序优雅停机。
- 密钥一律通过 Secret 注入（`stringData` 或 `secrets.*` values），敏感值如 `jwtSecret`/`encryptionKey` 在注释中标注“生产必须 ≥32 字符且含大写字母与数字”，禁止硬编码于 ConfigMap。
- 脚本统一使用 `set -e` / `set -euo pipefail` 开头，并以 `[INFO]/[WARN]/[ERROR]` 彩色前缀函数输出日志，参数通过环境变量覆盖（如 `NAMESPACE`、`RELEASE_NAME`、`ENVIRONMENT`）。
- Helm 模板与 `k8s/` 静态清单保持资源名称一致（如 `xagent-api`、`xagent-worker`、`xagent-beat`、`xagent-config`、`xagent-secrets`），使两者可互换部署同一套应用。

`deployment/scripts/deploy.sh` 为统一入口，默认使用 `NAMESPACE=xagent RELEASE_NAME=xagent ENVIRONMENT=production`，自动加载 `values-${ENVIRONMENT}.yaml`；`deployment/rollback.sh` 支持 `-v/--version` 指定目标镜像 tag、`-d/--database` 联动执行 `migrate.py rollback`；`k8s/deployment.yml` 可直接 `kubectl apply -f deployment/k8s/deployment.yml` 完成全栈部署；`docker-compose.monitoring.yml` 用于本地启动监控栈。

## 3. 故障原因分析

### 3.1 直接原因

**应用进程内存溢出（OOM）**

- **症状**: 应用进程被操作系统杀死
- **日志证据**:
  ```
  [2026-05-28 14:20:15] ERROR: java.lang.OutOfMemoryError: Java heap space
  [2026-05-28 14:20:15] ERROR: Process killed by OOM killer
  ```
- **资源使用**:
  - 内存限制: 2GB
  - 实际使用: 2.1GB
  - 超出: 100MB

### 3.2 根本原因

**内存泄漏 - 缓存未正确释放**

**分析过程**:

1. **代码审查**
   - 发现 `CacheManager` 类中的缓存未设置过期时间
   - 缓存条目无限增长
   - 导致内存持续增加

2. **代码位置**
   ```python
   # backend/app/core/cache.py, 第45行
   def add_to_cache(key, value):
       self.cache[key] = value  # 缺少过期时间设置
   ```

3. **影响范围**
   - 缓存大小: 1.8GB
   - 缓存条目数: 500,000+
   - 增长速率: 100MB/小时

4. **触发条件**
   - 高并发请求（>1000 req/s）
   - 缓存命中率低（<50%）
   - 缓存清理机制失效

### 3.3 根本原因树

```
应用进程OOM
├─ 内存使用过高
│  ├─ 缓存无限增长
│  │  ├─ 缺少过期时间设置
│  │  ├─ 缺少大小限制
│  │  └─ 清理机制失效
│  ├─ 连接池泄漏
│  │  └─ 连接未正确关闭
│  └─ 其他内存泄漏
│     └─ 第三方库问题
└─ 内存限制不足
   ├─ 容器内存配置过低
   └─ 应用内存需求增加
```

## 4. 根本原因详细分析

### 4.1 缓存管理问题

**问题描述**:
缓存系统没有实现过期时间和大小限制，导致缓存无限增长。

**代码分析**:
```python
# 问题代码
class CacheManager:
    def __init__(self):
        self.cache = {}  # 无限制的字典
    
    def add(self, key, value):
        self.cache[key] = value  # 直接添加，无过期时间
    
    def get(self, key):
        return self.cache.get(key)
    
    # 缺少清理方法
```

**影响**:
- 缓存条目无限增长
- 内存持续增加
- 最终导致OOM

### 4.2 监控告警缺陷

**问题描述**:
缺少内存使用率告警，无法提前发现问题。

**监控配置**:
```yaml
# 缺少的告警规则
alerts:
  memory_usage_high:
    threshold: 80%  # 缺少此告警
    duration: 5m
```

**影响**:
- 无法提前预警
- 问题发展到OOM才被发现
- 缺少调查时间

### 4.3 容量规划不足

**问题描述**:
应用内存配置未根据实际需求调整。

**配置分析**:
```yaml
# docker-compose.yml
xagent-api:
  mem_limit: 2g  # 配置过低
  # 实际需求: 3-4g
```

**影响**:
- 内存压力大
- 容易触发OOM
- 性能下降

## 6. 预防措施

### 6.1 立即行动（24小时内）

**优先级**: 高

1. **修复缓存管理**
   ```python
   # 修复代码
   class CacheManager:
       def __init__(self, max_size=1000, ttl=3600):
           self.cache = {}
           self.max_size = max_size
           self.ttl = ttl
       
       def add(self, key, value):
           if len(self.cache) >= self.max_size:
               self.evict_oldest()
           self.cache[key] = {
               'value': value,
               'timestamp': time.time()
           }
       
       def evict_oldest(self):
           oldest_key = min(self.cache, key=lambda k: self.cache[k]['timestamp'])
           del self.cache[oldest_key]
   ```

2. **增加内存限制**
   ```yaml
   xagent-api:
     mem_limit: 4g  # 增加到4GB
   ```

3. **部署修复版本**
   ```bash
   git commit -m "Fix: 修复缓存内存泄漏问题"
   git push origin main
   docker build -t xagent:v1.0.1 .
   docker-compose up -d
   ```

2. **实现缓存清理机制**

   ```python
   def cleanup_expired_cache():
       current_time = time.time()
       expired_keys = [
           k for k, v in self.cache.items()
           if current_time - v['timestamp'] > self.ttl
       ]
       for key in expired_keys:
           del self.cache[key]
   ```

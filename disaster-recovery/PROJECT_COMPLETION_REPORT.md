## 架构设计

### 多区域部署架构

```
┌─────────────────────────────────────────────────────────┐
│              全局负载均衡器 (Route53)                    │
└────────────────┬──────────────────────────┬─────────────┘
                 │                          │
        ┌────────▼────────┐        ┌────────▼────────┐
        │   主区域 (US-E)  │        │  备用区域 (US-W) │
        │   (活跃)         │        │  (热备)          │
        └────────┬────────┘        └────────┬────────┘
                 │                          │
        ┌────────▼────────┐        ┌────────▼────────┐
        │  应用层 (3x)     │        │  应用层 (3x)     │
        │  - API服务      │        │  - API服务      │
        │  - Worker       │        │  - Worker       │
        └────────┬────────┘        └────────┬────────┘
                 │                          │
        ┌────────▼────────┐        ┌────────▼────────┐
        │  数据层          │◄──────►│  数据层          │
        │  - PostgreSQL   │        │  - PostgreSQL   │
        │  - Redis        │        │  - Redis        │
        │  - Qdrant       │        │  - Qdrant       │
        │  - Neo4j        │        │  - Neo4j        │
        └────────┬────────┘        └────────┬────────┘
                 │                          │
        ┌────────▼────────┐        ┌────────▼────────┐
        │  备份存储        │        │  备份存储        │
        │  - S3 (主)      │        │  - S3 (副本)    │
        │  - 本地快照     │        │  - 本地快照     │
        └─────────────────┘        └─────────────────┘
```

### 数据同步拓扑

```
主区域 PostgreSQL (Primary)
    ↓ (WAL流复制, <1秒)
备用区域 PostgreSQL (Standby)
    ↓ (异步复制)
S3 备份存储
    ↓ (跨区域复制)
备用区域 S3 备份存储

主区域 Redis (Master)
    ↓ (实时同步, <5秒)
备用区域 Redis (Replica)

主区域 Qdrant (Primary)
    ↓ (快照 + 增量, <10分钟)
备用区域 Qdrant (Replica)

主区域 Neo4j (Primary)
    ↓ (事务日志, <10分钟)
备用区域 Neo4j (Replica)
```

## 操作流程

### 故障检测到恢复的完整流程

```
T+0秒: 故障发生
  ↓
T+10秒: 健康检查失败
  ↓
T+30秒: 触发告警
  ↓
T+45秒: 自动故障转移开始
  ↓
T+60秒: DNS更新完成
  ↓
T+90秒: 流量转移完成
  ↓
T+120秒: 恢复验证开始
  ↓
T+300秒: 恢复验证完成
  ↓
T+600秒: 运维团队接收通知
  ↓
T+1800秒: 故障根因分析开始
```

### 快速命令参考

```bash
# 检查系统状态

# 持续监控
```

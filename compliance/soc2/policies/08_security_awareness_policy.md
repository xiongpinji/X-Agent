# 安全意识与培训策略 (Security Awareness Policy)

| 字段 | 值 |
|---|---|
| 文档编号 | XA-POL-008 |
| 版本 | 1.0 |
| 生效日期 | 2026-07-21 |
| TSC 映射 | CC1.4 |

## 1. 培训要求

| 对象 | 频率 | 内容 |
|---|---|---|
| 新员工 | 入职 30 天内 | 安全基础 + 策略概览 |
| 全员 | 年度 | 钓鱼防范 + 数据保护 |
| 开发 | 年度 | 安全编码 + OWASP Top 10 |
| 管理层 | 年度 | 合规义务 + 事件管理 |

## 2. 专项培训

- 安全编码: SAST 工具使用、依赖审计
- 事件响应: 角色演练、升级流程
- 隐私保护: GDPR/个保法 要求

## 3. 考核

- 培训完成率: 100% (强制)
- 钓鱼模拟: 季度，点击率 < 5%
- 记录: 培训日志保存 3 年

# 加密与密钥管理策略 (Encryption & Key Management Policy)

| 字段 | 值 |
|---|---|
| 文档编号 | XA-POL-011 |
| 版本 | 1.0 |
| 生效日期 | 2026-07-21 |
| TSC 映射 | CC6.7, CC9.1 |

## 1. 加密要求

| 场景 | 标准 |
|---|---|
| 传输中 | TLS 1.2+ (HSTS 强制) |
| 存储中 | AES-256-GCM (信封加密) |
| 密钥管理 | KMS (Local/Vault/AWS) |

## 2. 密钥管理

- 主密钥 (KEK): KMS 管理，永不导出
- 数据密钥 (DEK): 随机生成，用后销毁
- 轮换: 自动 90 天轮换
- 版本: 旧版密钥保留用于解密

## 3. 禁止事项

- 禁止硬编码密钥
- 禁止明文存储敏感数据
- 禁止使用已废弃算法 (MD5/SHA1/DES)
- 禁止在日志中输出密钥

### 1. 企业功能核心模块

**文件路径**：`backend/app/core/enterprise.py`

**功能概述**：
- 多租户管理系统
- 企业用户管理
- 团队协作管理
- API 密钥管理
- 审计日志系统
- 权限管理引擎
- 合规报告生成

**核心类**：
```python
# 数据模型
- EnterpriseUser          # 企业用户
- Team                    # 团队
- EnterpriseTenant        # 企业租户
- APIKey                  # API 密钥
- AuditLog                # 审计日志
- AccessPolicy            # 访问策略
- ComplianceReport        # 合规报告

# 存储层
- EnterpriseUserStore     # 用户存储
- TeamStore               # 团队存储
- EnterpriseTenantStore   # 租户存储
- APIKeyStore             # API 密钥存储
- AuditLogStore           # 审计日志存储

# 服务层
- EnterpriseService       # 企业服务主类

# 枚举
- TenantPlan              # 租户计划
- RoleType                # 角色类型
- PermissionType          # 权限类型
- AuditEventType          # 审计事件类型
```

**关键方法**：
```python
# 权限检查
check_permission(user, permission) -> bool
check_resource_access(user, resource_type, resource_id, action) -> bool

# 审计日志
log_event(tenant_id, event_type, resource_type, ...) -> AuditLog

# 合规报告
generate_compliance_report(tenant_id, report_type, period_start, period_end) -> ComplianceReport
```

**使用示例**：
```python
from backend.app.core.enterprise import EnterpriseService, EnterpriseUser, RoleType

# 创建服务
service = EnterpriseService()

# 创建用户
user = EnterpriseUser(
    email="alice@acme.com",
    display_name="Alice Johnson",
    tenant_id="tenant-001",
    role=RoleType.DEVELOPER
)
created_user = service.users.create(user)

# 检查权限
has_permission = service.check_permission(user, PermissionType.AGENT_EXECUTE)

# 记录审计事件
service.log_event(
    tenant_id="tenant-001",
    event_type=AuditEventType.USER_CREATED,
    resource_type="user",
    resource_id=created_user.id,
    action="create"
)
```

**用户管理**（6 个端点）：
```

GET    /api/v1/enterprise/tenants/{tenant_id}/users/{user_id}
PUT    /api/v1/enterprise/tenants/{tenant_id}/users/{user_id}
DELETE /api/v1/enterprise/tenants/{tenant_id}/users/{user_id}
GET    /api/v1/enterprise/tenants/{tenant_id}/users
```

**团队管理**（5 个端点）：
```
POST   /api/v1/enterprise/tenants/{tenant_id}/teams
GET    /api/v1/enterprise/tenants/{tenant_id}/teams/{team_id}
GET    /api/v1/enterprise/tenants/{tenant_id}/teams
POST   /api/v1/enterprise/tenants/{tenant_id}/teams/{team_id}/members/{user_id}
DELETE /api/v1/enterprise/tenants/{tenant_id}/teams/{team_id}/members/{user_id}
```

**API 密钥管理**（3 个端点）：
```
POST   /api/v1/enterprise/tenants/{tenant_id}/api-keys
GET    /api/v1/enterprise/tenants/{tenant_id}/api-keys
DELETE /api/v1/enterprise/tenants/{tenant_id}/api-keys/{key_id}
```

**审计和合规**（4 个端点）：
```
GET    /api/v1/enterprise/tenants/{tenant_id}/audit-logs
GET    /api/v1/enterprise/tenants/{tenant_id}/compliance-reports
POST   /api/v1/enterprise/tenants/{tenant_id}/compliance-reports
```

**权限管理**（4 个端点）：
```
GET    /api/v1/enterprise/tenants/{tenant_id}/users/{user_id}/permissions
POST   /api/v1/enterprise/tenants/{tenant_id}/users/{user_id}/permissions/{permission}
DELETE /api/v1/enterprise/tenants/{tenant_id}/users/{user_id}/permissions/{permission}
```

**SSO 配置**（2 个端点）：
```
PUT    /api/v1/enterprise/tenants/{tenant_id}/sso-config
GET    /api/v1/enterprise/tenants/{tenant_id}/sso-config
```

**使用示例**：
```bash
# 创建租户
curl -X POST http://localhost:8000/api/v1/enterprise/tenants \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Acme Corp",
    "plan": "enterprise",
    "organization_name": "Acme Corporation"
  }'

# 创建用户
curl -X POST http://localhost:8000/api/v1/enterprise/tenants/tenant-001/users \
  -H "Content-Type: application/json" \
  -d '{
    "email": "alice@acme.com",
    "display_name": "Alice Johnson",
    "role": "developer"
  }'

# 查询审计日志
curl -X GET "http://localhost:8000/api/v1/enterprise/tenants/tenant-001/audit-logs?start_date=2026-05-01&end_date=2026-05-31"
```

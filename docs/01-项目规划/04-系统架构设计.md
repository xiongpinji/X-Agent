## 当前架构主线

当前仓库的主体仍然可以概括为五层：

### 五层架构模型

```
┌──────────────────────────────────────────────────┐
│              接入层 (Access Layer)              │
│  Web UI · REST API · CLI · 桌面入口 · 外部集成    │
├──────────────────────────────────────────────────┤
│              编排层 (Orchestration Layer)       │

│  记忆系统 · 追踪系统 · 审批 · 进化接口            │
├──────────────────────────────────────────────────┤

├──────────────────────────────────────────────────┤
│              基础设施层 (Infrastructure Layer)  │
│  JSON 文件 · SQLite · PostgreSQL · Qdrant · Langfuse │
└──────────────────────────────────────────────────┘
```

## 当前代码里的主流程

### 1. 用户请求到执行结果

```text
用户请求
  → FastAPI 接口
  → 认证 / 权限 / 作用域检查
  → Agent / Workflow / Memory / Browser / Tool 等核心模块
  → 追踪、审计、日志、观测
  → 返回结果
```

### 2. Memory 读写链路

```text
API 请求
  → memory 接口
  → core memory / service memory
  → 本地或外部后端
  → 审计 / Langfuse 记录
```

### 3. Readiness 检查链路

```text
GET /ready
  → memory
  → qdrant
  → trace
  → runs
  → workflows
  → audit
  → browser
  → observability
```

## 当前架构需要支持的主闭环

### 1. 编排闭环
- 接收任务
- 判断能力缺口
- 拆分任务
- 委派子代理
- 调用工具
- 处理结果
- 进入自我进化

### 2. 记忆闭环
- 运行前检索
- 运行中注入
- 运行后写回
- 会话连续
- 修订 / 回滚 / 巩固
- 多源检索
- 共享 / 协作记忆
- 长期沉淀

### 3. 创造力闭环
- 发现缺口
- 主动检索开源资源
- 分类、筛选、组合
- 转成技能 / 工具 / 适配器 / 工作流节点
- 写入记忆并推动进化
- 生成对比报告 / 风险报告 / 接入计划
- 支持人工复核后晋级

### 4. 可观测闭环
- trace
- run
- audit
- correlation
- replay / debug
- overview / metrics / ops

### 5. 安全与治理闭环

- 高风险审批
- 破坏性操作防护
- 可追踪 / 可审计 / 可回滚

### 6. 插件与扩展闭环
- 插件注册 / 运行 / 沙箱 / 安装 / 卸载
- 第三方集成
- 工具适配器

### 7. 创造力闭环

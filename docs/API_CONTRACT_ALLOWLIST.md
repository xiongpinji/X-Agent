# API Contract Allowlist

- `/api/health` - public health alias used by frontend bootstrap.
- `/api/v1` - base URL string, not a callable route.
- `/api/v1/agent/runs/{param}` - legacy client compatibility path kept out of first-version navigation while backend run APIs are consolidated.
- `/api/v1/creative-studio/shot-video` - second-batch external video API contract kept out of the first-version mounted app until owner-approved rollout.
- `/api/v1/creative-studio/video-provider-status` - second-batch external video provider contract kept out of the first-version mounted app until owner-approved rollout.
- `/api/v1/creative-studio/video-workflow` - second-batch external video workflow contract kept out of the first-version mounted app until owner-approved rollout.

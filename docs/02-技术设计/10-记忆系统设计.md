## 记忆系统在整体架构中的定位

记忆系统不是附属模块，而是 X-Agent 的核心基础能力之一，承担以下职责：

- 为 Agent 编排和执行提供上下文
- 维护会话连续性
- 记录任务经验和轨迹
- 支持长期沉淀与学习
- 为工作流、协作和自我进化提供共享底座

## 当前已实现的能力

### 1. 记忆结构
当前记忆系统已经具备你要的结构基础：

- 分层记忆设计
- 会话记忆 / 会话连续性
- 短期记忆
- 长期记忆
- 记忆修订 / 版本回滚
- 记忆共享 / 作用域管理

### 2. 记忆写入
当前写入能力支持：

- 执行后自动写入经验
- 写入时绑定会话 / 任务 / trace
- 先总结再写入
- 允许手动覆盖或补充写入

### 3. 记忆检索
当前检索能力支持：

- 执行前检索上下文
- 多源检索（关键词 / 向量 / 其他）
- 优先最近会话与近期经验
- 优先与当前任务最相关的记忆
- 检索结果展示相关度 / 分数

### 4. 记忆巩固
当前巩固能力支持：

- 自动巩固
- 允许手动触发巩固
- 从 Agent 运行中沉淀经验
- 重要记忆自动提升为长期记忆
- 记忆污染 / 冲突检查

### 5. 会话与连续性
当前会话能力支持：

- 上下文可跨轮次延续
- 支持恢复会话
- 保留状态快照
- 关键记忆置顶 / 固定
- 保留最近历史窗口

### 6. 记忆治理
当前治理能力支持：

- 记忆版本 / 修订
- 记忆回滚
- 污染 / 冲突检查
- 允许人工纠正
- 共享范围 / 作用域控制

### 7. 关联与共享
当前还支持：

- 记忆与 session 关联
- 共享 / 取消共享
- 作用域路由
- 导入 / 导出
- consolidation
- 统计与快照

## 当前记忆写入内容要求

结合你的需求，记忆写入时应保留以下内容：

- 任务摘要
- 执行轨迹 / trace 关联
- 工具结果摘要
- 委派摘要
- 反思 / 学习内容
- 能力提升记录
- 绑定会话 / task / agent / tenant

这意味着记忆写入不是只存一段文本，而是要存整个任务闭环的经验结构。

---

## 当前记忆检索内容要求

运行前检索时要优先注入：

- 最近会话
- 最近任务运行记录
- 与当前任务强相关的记忆
- 与当前 Agent 角色相关的记忆
- 共享 / 协作记忆
- 长期记忆

并且上下文注入方式要支持：

- 直接注入上下文
- 先总结再注入
- 按相关度排序后挑选
- 分阶段逐步注入
- 受 token 预算控制

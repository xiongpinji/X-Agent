# X-Agent 问题跟踪系统配置指南

## 1. 概述

本文档介绍如何配置和使用X-Agent的问题跟踪系统，包括Jira/Linear的集成、工作流配置、自动化规则等。

## 2. 系统选择

### 2.1 Jira配置

**优势**:
- 功能完整
- 企业级支持
- 与Atlassian生态集成
- 强大的报告功能

**劣势**:
- 学习曲线陡
- 配置复杂
- 成本较高

**适用场景**: 大型企业、复杂工作流

### 2.2 Linear配置

**优势**:
- 界面简洁
- 快速上手
- 成本低
- 现代化设计

**劣势**:
- 功能相对简单
- 集成较少
- 报告功能有限

**适用场景**: 中小企业、快速迭代

### 2.3 推荐方案

- **小型团队** (1-5人): Linear
- **中型团队** (5-20人): Linear或Jira
- **大型企业** (20+人): Jira

## 3. Jira配置

### 3.1 项目创建

**步骤1: 创建项目**
1. 登录Jira
2. 点击"创建项目"
3. 选择项目类型: "Scrum"或"Kanban"
4. 填写项目信息:
   - 项目名称: X-Agent Support
   - 项目密钥: XASUP
   - 项目负责人: 支持团队负责人

**步骤2: 配置项目设置**
1. 进入项目设置
2. 配置问题类型
3. 配置工作流
4. 配置字段
5. 配置权限

### 3.2 问题类型配置

**创建问题类型**:

| 问题类型 | 图标 | 描述 |
|---------|------|------|
| Bug | 虫子 | 系统缺陷 |
| Task | 任务 | 支持任务 |
| Incident | 警告 | 事件/故障 |
| Request | 请求 | 功能请求 |
| Question | 问号 | 咨询问题 |

**配置步骤**:
1. 进入"问题类型"设置
2. 点击"创建问题类型"
3. 填写类型信息
4. 配置字段映射
5. 保存

### 3.3 工作流配置

**工作流状态**:
```
新建 → 已分配 → 进行中 → 等待客户 → 已解决 → 已关闭
  ↓                                      ↓
  └──────────────────────────────────────┘
                  已重新打开
```

**工作流转换规则**:

| 从状态 | 到状态 | 条件 | 操作 |
|--------|--------|------|------|
| 新建 | 已分配 | 自动 | 分配给支持人员 |
| 已分配 | 进行中 | 手动 | 开始处理 |
| 进行中 | 等待客户 | 手动 | 等待客户反馈 |
| 等待客户 | 进行中 | 自动 | 客户回复后 |
| 进行中 | 已解决 | 手动 | 问题解决 |
| 已解决 | 已关闭 | 自动 | 7天后自动关闭 |
| 已关闭 | 已重新打开 | 手动 | 客户反馈问题未解决 |

**配置步骤**:
1. 进入"工作流"设置
2. 创建新工作流或编辑现有工作流
3. 添加状态
4. 配置转换
5. 设置转换条件
6. 发布工作流

### 3.4 字段配置

**必填字段**:
- 问题标题 (Summary)
- 问题描述 (Description)
- 优先级 (Priority)
- 问题类型 (Issue Type)
- 分配人 (Assignee)

**自定义字段**:

| 字段名 | 类型 | 用途 |
|--------|------|------|
| 客户名称 | 文本 | 识别客户 |
| 优先级 | 下拉 | P0-P3 |
| 影响范围 | 下拉 | 影响程度 |
| 根本原因 | 文本 | 问题根因 |
| 解决方案 | 文本 | 解决方案 |
| SLA状态 | 下拉 | SLA达成情况 |
| 满意度 | 数字 | 客户满意度 |

**配置步骤**:
1. 进入"字段"设置
2. 点击"创建自定义字段"
3. 选择字段类型
4. 填写字段信息
5. 配置字段选项
6. 保存

### 3.5 权限配置

**角色定义**:

| 角色 | 权限 |
|------|------|
| 管理员 | 全部权限 |
| 支持经理 | 创建、编辑、删除、分配 |
| 支持人员 | 创建、编辑、分配给自己 |
| 客户 | 查看、创建、评论 |

**配置步骤**:
1. 进入"权限"设置
2. 定义角色
3. 分配权限
4. 添加用户到角色
5. 保存

### 3.6 自动化规则

**规则示例1: 自动分配P0问题**
```
触发条件: 优先级 = P0
操作: 分配给 = 技术总监
通知: 发送邮件给技术总监
```

**规则示例2: 自动升级超期问题**
```
触发条件: 状态 = 进行中 AND 创建时间 > 4小时
操作: 优先级提升一级
通知: 发送邮件给支持经理
```

**规则示例3: 自动关闭已解决问题**
```
触发条件: 状态 = 已解决 AND 最后更新 > 7天
操作: 状态变更为 = 已关闭
通知: 发送邮件给客户
```

**配置步骤**:
1. 进入"自动化"设置
2. 点击"创建规则"
3. 设置触发条件
4. 配置操作
5. 设置通知
6. 启用规则

## 4. Linear配置

**步骤1: 创建工作区**
1. 登录Linear
2. 点击"创建工作区"
3. 填写工作区信息:

**步骤2: 邀请团队成员**
1. 进入"设置" → "成员"
2. 点击"邀请成员"

4. 选择角色

**创建项目**:
1. 点击"创建项目"
2. 填写项目信息

**问题类型**:

- Task: 支持任务
- Incident: 事件
- Request: 请求

### 4.3 工作流配置

**自定义工作流**:
1. 进入"设置" → "工作流"
2. 创建新工作流
3. 添加状态
4. 配置转换
5. 保存

### 4.4 自定义字段

**添加字段**:

5. 配置邮件规则

### 5.2 Slack集成

```
1. 在Slack中安装Jira应用
2. 进入Jira设置
3. 配置Slack通知
4. 选择通知事件
5. 测试通知
```

**Linear Slack集成**:
```
1. 在Slack中安装Linear应用
2. 进入Linear设置
3. 配置Slack通知
4. 选择通知事件
5. 测试通知
```

### 5.3 API集成

**获取API密钥**:

Jira:
1. 进入"个人设置" → "安全"
2. 点击"创建API令牌"
3. 输入令牌名称
4. 复制令牌

Linear:
1. 进入"设置" → "API"
2. 点击"创建API密钥"
3. 复制密钥

**API调用示例**:

Jira创建问题:
```bash
curl -X POST https://your-domain.atlassian.net/rest/api/3/issue \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "fields": {
      "project": {"key": "XASUP"},
      "summary": "问题标题",
      "description": "问题描述",
      "issuetype": {"name": "Bug"},
      "priority": {"name": "High"}
    }
  }'
```

Linear创建问题:
```bash
curl -X POST https://api.linear.app/graphql \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "mutation { issueCreate(input: {teamId: \"...\", title: \"问题标题\", priority: 1}) { issue { id } } }"
  }'
```

## 7. 通知和告警

### 7.1 通知规则

**Jira通知**:
1. 进入"通知"设置
2. 创建通知规则
3. 设置触发条件
4. 选择通知方式
5. 保存规则

**通知事件**:
- 问题创建
- 问题分配
- 问题更新

### 7.2 告警配置

**告警条件**:
- SLA即将超期
- 问题长时间未更新
- 高优先级问题未分配
- 客户满意度低

**告警方式**:
- 邮件
- Slack
- 短信
- 电话

## 9. 最佳实践

### 9.1 问题描述规范

**标题规范**:
- 简洁明了 (50字以内)
- 包含关键信息
- 避免重复

**描述规范**:
- 清晰的问题陈述
- 重现步骤
- 预期结果
- 实际结果
- 系统环境

### 9.2 优先级评估

**P0**: 系统宕机、数据丢失
**P1**: 核心功能故障、严重性能问题
**P2**: 功能部分受影响、轻微性能问题
**P3**: 咨询问题、建议

### 9.3 工作流管理

- 及时更新问题状态
- 定期清理已关闭问题
- 使用标签分类问题
- 链接相关问题

### 9.4 团队协作

- 定期同步会议
- 及时沟通进展
- 共享知识和经验
- 相互支持和帮助

## 10. 故障排除

### 10.1 常见问题

**问题**: 邮件通知未收到
**解决**: 检查邮件配置、检查垃圾邮件、重新发送

**问题**: 自动化规则未触发
**解决**: 检查规则条件、检查权限、查看日志

**问题**: 报告数据不准确
**解决**: 检查数据映射、重新生成报告、检查时间范围

### 10.2 性能优化

- 定期清理过期数据
- 优化查询性能
- 使用缓存
- 限制报告范围

## 11. 安全和合规

### 11.1 访问控制

- 基于角色的访问控制 (RBAC)
- 定期审查权限
- 撤销离职员工权限
- 审计日志

### 11.2 数据保护

- 加密敏感数据
- 定期备份
- 访问日志
- 合规审计

## 12. 迁移指南

3. 准备数据

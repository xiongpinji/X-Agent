## 什么是MCP插件

### MCP是什么？

MCP（Model Context Protocol）是一个开放的协议标准，用于连接AI模型与外部服务和工具。

### MCP插件有什么用？

MCP插件扩展了X-Agent的功能，让你可以：

- 🔌 连接外部服务（GitHub、数据库、文件系统等）
- 🛠️ 使用专业工具（数据分析、代码生成、自动化等）
- 📊 访问和管理数据（查询数据库、读写文件等）
- 🚀 自动化工作流（集成多个服务、自动执行任务等）

### 为什么使用MCP插件？

- **无需离开X-Agent**：在X-Agent中直接使用外部服务
- **简单易用**：小白友好的界面和文档
- **安全可靠**：沙箱隔离、权限管理、安全审核
- **高效协作**：与AI助手无缝协作

## 快速开始

### 5分钟安装第一个插件

#### 步骤1：打开插件市场

在X-Agent中，点击左侧菜单的"插件市场"。

#### 步骤2：搜索插件

在搜索框中输入"GitHub"，找到"GitHub助手"插件。

#### 步骤3：查看插件详情

点击插件卡片，查看：
- 插件功能说明
- 使用示例
- 用户评价
- 安装数量

#### 步骤4：安装插件

点击"安装"按钮。

#### 步骤5：配置插件

安装完成后，点击"配置"按钮：
1. 获取GitHub Personal Access Token
2. 在配置界面输入Token
3. 点击"保存"

#### 步骤6：开始使用

在X-Agent对话中输入：
```
列出我的GitHub仓库
```

X-Agent会自动调用GitHub插件，显示你的仓库列表。

## 安装插件

### 从插件市场安装

#### 方法1：搜索安装

1. 打开插件市场
2. 在搜索框中输入插件名称或关键词
3. 点击搜索结果中的插件
4. 点击"安装"按钮
5. 等待安装完成

#### 方法2：浏览分类安装

1. 打开插件市场
2. 选择分类（开发工具、数据分析、自动化等）
3. 浏览插件列表
4. 点击感兴趣的插件
5. 点击"安装"按钮

#### 方法3：查看推荐安装

1. 打开插件市场
2. 查看"推荐"或"热门"部分
3. 点击推荐的插件
4. 点击"安装"按钮

### 从本地安装

如果你有插件的本地文件：

1. 打开插件市场
2. 点击"从本地安装"
3. 选择插件文件（.zip格式）
4. 点击"安装"

### 安装进度

安装过程中，你会看到进度条：

```
安装中... 25%
正在下载插件文件...
```

安装完成后，会显示：

```
✓ 安装完成！
插件已准备好使用。
```

## 配置插件

### 基本配置

大多数插件需要配置才能使用。

#### 步骤1：打开配置界面

1. 在X-Agent中，点击左侧菜单的"已安装插件"
2. 找到要配置的插件
3. 点击插件卡片上的"配置"按钮

#### 步骤2：填写配置信息

根据插件的要求填写配置信息。常见的配置项：

- **API密钥**：用于认证的密钥或Token
- **主机地址**：服务器地址（如数据库主机）
- **端口号**：服务端口
- **用户名/密码**：登录凭证
- **超时时间**：请求超时时间

#### 步骤3：保存配置

填写完成后，点击"保存"按钮。

### 配置示例

#### GitHub插件配置

```
GitHub Token: gh_example_token_redacted
超时时间: 30秒
```

#### 数据库插件配置

```
数据库类型: PostgreSQL
主机: localhost
端口: 5432
用户名: postgres
密码: ••••••••
数据库名: mydb
超时时间: 30秒
```

#### 文件系统插件配置

```
允许访问的目录:
  - /home/user/documents
  - /tmp
最大文件大小: 100 MB
启用写入操作: 是
```

### 安全提示

- ⚠️ **不要分享API密钥**：API密钥是敏感信息，不要分享给他人
- 🔒 **使用强密码**：如果需要输入密码，使用强密码
- 🛡️ **定期更新Token**：定期更新API Token以保持安全
- 🔐 **限制权限**：只授予插件必要的权限

## 使用插件

### 在对话中使用插件

#### 方法1：直接提问

在X-Agent对话中直接提问，X-Agent会自动调用相关插件：

```
用户: 列出我的GitHub仓库
X-Agent: 正在调用GitHub插件...
[显示仓库列表]
```

#### 方法2：明确指定插件

如果有多个插件可以完成任务，你可以明确指定：

```
用户: 使用GitHub插件列出我的仓库
X-Agent: 正在使用GitHub插件...
[显示仓库列表]
```

#### 方法3：链式调用

X-Agent可以自动链式调用多个插件：

```
用户: 从GitHub获取我的仓库，然后分析代码质量
X-Agent: 
1. 正在调用GitHub插件获取仓库...
2. 正在调用代码分析插件...
[显示分析结果]
```

### 常见使用场景

#### 场景1：查询数据

```
用户: 查询数据库中所有用户的信息
X-Agent: 正在调用数据库插件...
[显示查询结果]
```

#### 场景2：文件操作

```
用户: 读取/home/user/documents/readme.txt文件
X-Agent: 正在调用文件系统插件...
[显示文件内容]
```

#### 场景3：自动化任务

```
用户: 在GitHub上创建一个新的Issue
X-Agent: 正在调用GitHub插件...
✓ Issue已创建
[显示Issue链接]
```

### 查看插件结果

插件执行完成后，X-Agent会显示结果：

```
✓ 执行成功
结果:
[显示详细结果]
```

如果出错，会显示：

```
✗ 执行失败
错误: [错误信息]
```

## 管理插件

### 查看已安装插件

1. 点击左侧菜单的"已安装插件"
2. 查看已安装的插件列表
3. 每个插件显示：
   - 插件名称
   - 版本号
   - 状态（已启用/已禁用）
   - 安装时间

### 启用/禁用插件

#### 禁用插件

如果你暂时不想使用某个插件：

1. 在已安装插件列表中找到插件
2. 点击插件卡片上的"禁用"按钮
3. 插件会被禁用，但不会被卸载

#### 启用插件

重新启用已禁用的插件：

1. 在已安装插件列表中找到插件
2. 点击插件卡片上的"启用"按钮
3. 插件会被重新启用

### 更新插件

#### 检查更新

1. 在已安装插件列表中找到插件
2. 如果有新版本，会显示"有新版本"标签
3. 点击"更新"按钮

#### 更新过程

```
正在更新插件...
下载新版本... 50%
安装新版本...
✓ 更新完成！
```

### 卸载插件

#### 卸载步骤

1. 在已安装插件列表中找到插件
2. 点击插件卡片上的"卸载"按钮
3. 确认卸载
4. 插件会被卸载

#### 卸载后

- 插件会从X-Agent中移除
- 插件的配置会被删除
- 插件的数据会被清理

### 查看插件信息

点击插件卡片可以查看：

- **基本信息**：名称、版本、作者、许可证
- **功能说明**：插件能做什么
- **使用示例**：如何使用插件
- **用户评价**：其他用户的评价
- **安装数量**：有多少人安装了这个插件

## 常见问题

### Q: 如何获取GitHub Token？

A: 
1. 访问 https://github.com/settings/tokens
2. 点击"Generate new token"
3. 选择"Personal access tokens"
4. 输入Token名称
5. 选择权限（至少需要repo权限）
6. 点击"Generate token"
7. 复制Token（只会显示一次）
8. 在X-Agent中粘贴Token

### Q: 插件安装失败怎么办？

A: 
1. 检查网络连接
2. 检查磁盘空间是否充足
3. 尝试重新安装
4. 如果仍然失败，查看错误日志
5. 联系插件开发者

### Q: 如何卸载插件？

A:
1. 在已安装插件列表中找到插件
2. 点击"卸载"按钮
3. 确认卸载
4. 插件会被卸载

### Q: 插件配置丢失了怎么办？

A:
1. 重新打开插件配置界面
2. 重新填写配置信息
3. 点击"保存"

### Q: 如何报告插件问题？

A:
1. 在插件详情页面点击"报告问题"
2. 描述问题
3. 提交报告
4. 插件开发者会收到你的反馈

### Q: 插件支持哪些操作系统？

A: 大多数插件支持Windows、macOS和Linux。具体支持的操作系统在插件详情页面有说明。

### Q: 插件会收集我的数据吗？

A: 插件只会收集执行任务所需的数据。具体的数据收集政策在插件详情页面有说明。

### Q: 如何更新插件？

A:
1. 在已安装插件列表中找到插件
2. 如果有新版本，点击"更新"按钮
3. 等待更新完成

## 故障排除

### 插件无法安装

**症状**：点击安装后没有反应或显示错误

**解决方案**：
1. 检查网络连接
2. 检查磁盘空间
3. 尝试重新安装
4. 查看错误日志

### 插件无法使用

**症状**：插件已安装但无法调用

**解决方案**：
1. 检查插件是否已启用
2. 检查插件配置是否正确
3. 检查API密钥是否有效
4. 查看错误日志

### 插件执行缓慢

**症状**：插件执行时间很长

**解决方案**：
1. 检查网络连接
2. 检查服务器状态
3. 增加超时时间
4. 检查系统资源使用情况

### 插件返回错误

**症状**：插件执行失败并显示错误信息

**解决方案**：
1. 阅读错误信息
2. 检查输入参数是否正确
3. 检查插件配置是否正确
4. 查看插件文档

### 如何查看日志

1. 点击左侧菜单的"设置"
2. 选择"日志"
3. 查看插件执行日志

### 如何获取帮助

- 📖 查看插件文档
- 💬 在X-Agent中提问
- 🐛 报告问题
- 📧 联系插件开发者

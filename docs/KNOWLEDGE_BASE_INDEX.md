## 学习路径

### 初级用户 (1-2小时)

1. **第一步：理解基础** (15分钟)
   - 阅读 [README](./README.md)
   - 查看 [快速入门](./QUICK_START_GUIDE.md)

2. **第二步：安装和运行** (30分钟)
   - 按照 [安装指南](./INSTALL.md) 安装
   - 运行 [Hello World 示例](./EXAMPLES_TEMPLATES.md#示例-1基础-agent-创建)

3. **第三步：学习基础概念** (45分钟)
   - 学习 [Agent 基础](./tutorials/01-agent-basics.md)
   - 查看 [API 示例](./API_EXAMPLES.md)

4. **第四步：解决问题** (15分钟)
   - 查看 [FAQ](./COMPREHENSIVE_FAQ.md)
   - 参考 [故障排除](./COMPREHENSIVE_TROUBLESHOOTING.md)

### 中级用户 (4-6小时)

1. **第一步：深入学习** (2小时)
   - 学习 [工作流编排](./tutorials/02-workflow-orchestration.md)
   - 学习 [记忆系统](./tutorials/03-memory-system.md)
   - 学习 [浏览器自动化](./tutorials/04-browser-automation.md)

2. **第二步：实践项目** (2小时)
   - 创建自定义 Agent
   - 构建工作流
   - 集成工具

3. **第三步：优化和部署** (2小时)
   - 阅读 [性能优化](./PERFORMANCE_OPTIMIZATION_GUIDE.md)
   - 学习 [部署指南](./DEPLOYMENT_GUIDE.md)

### 高级用户 (8-12小时)

1. **第一步：架构理解** (2小时)
   - 研究 [架构设计](./ARCHITECTURE_DESIGN.md)
   - 学习 [多 Agent 协作](./docs/02-技术设计/12-多Agent协作使用指南.md)

2. **第二步：开发扩展** (4小时)
   - 学习 [插件开发](./PLUGIN_DEVELOPMENT_GUIDE.md)
   - 学习 [API 集成](./API_INTEGRATION_GUIDE.md)

3. **第三步：生产部署** (3小时)
   - 学习 [安全指南](./SECURITY_GUIDE.md)
   - 学习 [监控](./MONITORING.md)
   - 学习 [运维指南](./OPERATIONS.md)

4. **第四步：贡献代码** (3小时)
   - 阅读 [贡献指南](./CONTRIBUTING.md)
   - 阅读 [开发者指南](./DEVELOPER_GUIDE.md)
